# AI音声動画づくり（エバー講座・ナーチャリング音声）引き継ぎ書

台本テキストを入れると「スライド＋AI音声＋テロップ＋BGM」の MP4 が自動でできる仕組み。

## 決めたこと

- 納品は **MP4 だけ**（三浦さんは PowerPoint を持っていないため .pptx は使わない）
- 色は紺（#1F3A5F）とオレンジ（#E8833A）。ロゴは「ありがとうグループ」の文字だけ（`logo/`）
- しゃべる速さ（1.08倍）と BGM の音量（6%）は「ちょうど良い」と確認済み
- テロップは読み上げに合わせて1行ずつ、画面下に出す
- 場面切り替えはフェード、話し終わったら次のスライドへ
- [三浦が確認・記入] の部分は読み上げで飛ばし、画面には黄色いマーカーで残す
- 読み間違いは `build.py` の `READING_FIX` に足す（画面の文字はそのまま、読み上げだけ直る）
  - 例：「資格はいりません」→「は」を「わ」、「たくさんの方」「くれた方」→「方」を「かた」
  - ビルドのたびに「方」と「は」の読みを `[読み確認]` として一覧に出すので、そこを見て直す
- Seedance などの動画生成AIは今は使わない。入れるなら三浦さんの実際の作業動画を差し込む方がよい

## 動かし方

```bash
pip install python-pptx pyopenjtalk-prebuilt "numpy<2" imageio-ffmpeg pymupdf pillow lxml
apt-get install -y libreoffice-impress fonts-noto-cjk fonts-mplus
cd ai-voice-video
python3 build.py scripts/Q1第1回.txt Q1第1回 "第1回　エアコン清掃独立のリアル"
# → Q1第1回.mp4 ができる（作業ファイルは Q1第1回_work/）
```

## 台本ファイルの書き方（`scripts/*.txt`）

```
=== スライドのタイトル
[screen]
画面に出す文字（1行ずつ。「・」で始まると箇条書き、「※」は小さい注意書き、「→」はオレンジの強調）
[voice]
読み上げる文（1行が1つのテロップになる）

空行で段落を分ける（段落のあいだは少し長めに間をあける）
```
