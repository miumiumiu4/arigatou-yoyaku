# Claude in Chrome に貼るプロンプト（Gemini の声選びと APIキーの登録）

下の枠の中をそのまま Chrome の Claude に貼る。

```
Google AI Studio で講座動画の声を選び、Gemini の APIキーを Claude Code の環境に登録する作業を手伝ってください。
アカウントは miumiumiu4@gmail.com です。

■ 守ること
・APIキーの「作成」「コピー」「貼り付け」は三浦本人がやります。あなたはその画面を開いたら止まって、私に「ここで作成してください」と伝えてください。キーの文字列を読み上げたり、メモやチャットに書いたりしないでください
・お金がかかる操作（請求先の登録、有料プランへの切り替え、購入）はしないでください。画面の状態を報告するだけにしてください
・AI Studio に貼ってよい文は、下の「試しの文」だけです。講座の台本は貼らないでください（無料枠では入力が学習に使われることがあるため）

■ 1. 声を選ぶ（AI Studio）
1. https://aistudio.google.com を開き、「Generate speech」（音声の生成）のページを開く
2. 設定で言語を「日本語」に絞る。2人で話す（multi-speaker）の形にする
3. 語り手（三浦役）の候補を3つ探す：落ち着いていて聞き疲れしない、30〜50代くらいの男性の声。使い道は「チューター（先生）」や「ナレーション」あたり
4. 聞き手（受講生役）の候補を3つ探す：明るく素直な声。語り手と聞き分けやすい声（高さや性別が違う方がよい）
5. 試しの文で鳴らして聞き比べる
   語り手：「こんにちは。ありがとうグループの三浦です。全部で7回。最後には、あなた自身の独立のロードマップができあがります。」
   聞き手：「7回で、ロードマップまでできるんですか？」
6. 演技の指示も試す：語り手に「warm, calm」、聞き手に「surprised, curious」
7. 候補の声の名前と、画面に書いてある短い説明（高さ・雰囲気）を表にまとめる。私が聞いて最終決定するので、再生できる状態で止めてください
8. 右上などにある「Get code」（コードを取得）を開き、使われているモデル名（例：gemini-…-tts のような文字列）と、声の指定の書き方を控える

■ 2. APIキーを作る画面まで案内する（AI Studio）
1. AI Studio の「Get API key」（APIキーを取得）のページを開く
2. すでにあるキーの一覧と、それぞれのプロジェクトが「無料枠（Free tier）」か「有料（Paid tier）」かを報告する（キーの文字列は報告しない）
3. 「Create API key」ボタンの場所を私に伝えて止まる → 三浦が作成してコピーする

■ 3. Claude Code の環境に登録する画面まで案内する
1. https://claude.ai/code を開き、「三浦のAI音声生成」のセッション（リポジトリ arigatou-yoyaku・クラウド）を開く
2. 画面上部のクラウド環境のメニュー →「Edit」（編集）を開く
3. 環境変数の欄の場所を私に伝えて止まる → 三浦が次の1行を入力して保存する
   GEMINI_API_KEY=（コピーしたキー）
4. ネットワークの設定（Network access）は変えなくてよい（generativelanguage.googleapis.com にはすでにつながることを確認済み）

■ 4. 最後に、Claude Code に貼る報告文を作ってください（キーの文字列は入れない）
・語り手の候補3つ（声の名前・説明）と、三浦が選んだ声
・聞き手の候補3つと、三浦が選んだ声
・Get code に出ていたモデル名と、声の指定の書き方
・APIキーを作ったプロジェクトが無料枠か有料か
・環境変数 GEMINI_API_KEY を登録したかどうか
```

## 登録したあと

- 環境変数は**新しいセッションから**読み込まれる。登録後は新しいセッションを開き、報告文と一緒に「黒板授業の冒頭を Gemini の声で作り直して」と頼む
- 有料の講座台本を無料枠で読ませるのは避ける。本番は有料（Paid tier）のプロジェクトのキーで作るのがおすすめ（規約は最新のものを確認）
