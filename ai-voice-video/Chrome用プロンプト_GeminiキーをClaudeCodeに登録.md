# Claude in Chrome に貼るプロンプト（Gemini の APIキーを Claude Code の環境に登録する）

下の枠の中をそのまま Chrome の Claude に貼る。

```
Gemini の APIキーを、Claude Code（claude.ai/code）の作業環境に登録する作業を手伝ってください。
アカウントは miumiumiu4@gmail.com です。講座動画のナレーションを Gemini の声で作るために使います。

■ 守ること
・APIキーの「作成」「コピー」「貼り付け」は三浦本人がやります。その画面を開いたら止まって、「ここで作成（またはコピー）してください」と私に伝えてください
・キーの文字列を読み上げたり、メモやチャットや報告文に書いたりしないでください
・お金がかかる操作（購入、プランの変更、請求先の変更）はしないでください。画面の状態を報告するだけにしてください
・AI Studio に講座の台本を貼らないでください。声を試すときは、下の「試しの文」だけを使ってください

■ 1. 20ドルを購入したプロジェクトとキーを確認する（Google AI Studio）
1. https://aistudio.google.com を開き、「Get API key」（APIキーを取得）のページを開く
2. キーの一覧から、20ドルを購入した（請求先を設定した）プロジェクトのキーを探す
3. そのプロジェクトが「有料（Paid tier）」になっているか、「無料枠（Free tier）」のままかを報告する（キーの文字列は報告しない）
4. そのプロジェクトにキーがまだなければ、「Create API key」ボタンの場所を伝えて止まる → 三浦が作成する
5. 使うキーの「コピー」ボタンの場所を伝えて止まる → 三浦がコピーする

■ 2. 声とモデル名を確認する（Google AI Studio）
1. 「Generate speech」（音声の生成）のページを開く
2. すでに声を選んであれば、その名前を控える。まだなら、次の2つを3つずつ候補に挙げて、私が聞いて決めるまで止まる
   ・語り手（三浦役）：落ち着いた、聞き疲れしない30〜50代くらいの男性の声
   ・聞き手（受講生役）：明るく素直な声（語り手と聞き分けやすい声）
   試しの文　語り手：「こんにちは。ありがとうグループの三浦です。」　聞き手：「7回で、ロードマップまでできるんですか？」
3. 「Get code」（コードを取得）を開き、使われているモデル名（gemini-…-tts のような文字列）をそのまま控える

■ 3. Claude Code の環境に登録する
1. https://claude.ai/code を開き、リポジトリ arigatou-yoyaku のセッション「三浦のAI音声生成」（クラウド）を開く
2. 画面上部のクラウド環境のメニュー →「Edit」（編集）を開き、環境変数の欄を探す
3. 次の4行を登録する。1行目のキーの部分は、三浦が自分で貼り付ける（あなたは入力欄の場所を伝えて止まる）
   GEMINI_API_KEY=（三浦がコピーしたキーを貼る）
   GEMINI_TTS_MODEL=（2-3で控えたモデル名）
   GEMINI_VOICE_N=（語り手の声の名前）
   GEMINI_VOICE_L=（聞き手の声の名前）
4. ネットワークの設定（Network access）は変えなくてよい（generativelanguage.googleapis.com にはつながることを確認済み）
5. 保存する

■ 4. 最後に、Claude Code に貼る報告文を作ってください（キーの文字列は入れない）
・キーのプロジェクトが有料（Paid tier）か無料枠か
・モデル名
・語り手と聞き手の声の名前
・4つの環境変数を登録して保存したかどうか
・報告文の最後に、この1行を入れる：「新しいセッションで、Gemini の声と Suno の曲（BGM）で Q1第1〜3回をキャラクター入りで作って」
```

## 登録したあと（三浦さんがやること）

1. 環境変数は**新しいセッションから**読み込まれる。claude.ai/code で arigatou-yoyaku の新しいセッションを開く
2. Chrome の Claude が作った報告文を貼る
3. 同じチャットに **Suno の曲のファイル（mp3 など）を添付**する（BGM として、話している間ずっと小さく流す）
