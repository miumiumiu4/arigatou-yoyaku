# 講座動画の「掛け合い台本」と「黒板の絵」を作るときの決まり

60分版の台本（~/claude/ever-offer/lessonN-script-60min.md）の1章を、二人の掛け合い台本と黒板の絵（場面ごとのJS）にする。
お手本：第1回の4章（scripts/Q1第1回_第1〜4章_60分版_掛け合い.txt、board/scenes/Q1第1回_第1〜4章.js）。必ず先に1つ読んで形をまねる。

## 台本（scripts/Q1第N回_第M章_60分版_掛け合い.txt）
- 1行＝`話者 | 演技の指示（短い英語） | セリフ`。話者は N（三浦）と L（受講生の女性）
- `# scene: 名前` で場面が切り替わる。名前は英小文字（その章の中で重ならないもの）。1場面＝60分版の「## x-y」1つが目安（短いものはまとめてよい）。1章で8〜12場面
- **N のセリフは、60分版の「読み上げ原稿」の文のまま**。言葉を足さない・変えない・削らない（区切り方だけ変えてよい。1行は1〜3文）
- **面談で出た言葉（「」の中）は一字も変えない**。数字・注意書きもそのまま
- L は短い相づち・驚き・質問だけ（1章で8〜12行）。L のセリフで新しい事実や数字を言わせない。原稿の中の「〜と思う方もいるかもしれません」のような問いかけを L の質問に置きかえるのは可（そのとき N の元の文は残す）
- ワークで「動画を止めて」と言う所は、その行のあとに `# wait: 4`
- 人名・地名・屋号・本の名前・著者名は出さない（原稿にもないはず）

## 黒板の絵（board/scenes/Q1第N回_第M章.js）
- 場面ごとに `(function () { const S = '名前', sc = scene(S); ... })();`
- 使える道具：`chalk(sc, 文字, x, y, 大きさ, 始まる秒, かける秒, {or:オレンジ, center:中央寄せ, kind:'pop'})`、`draw(sc, x, y, w, h, [パス], 秒, かける秒)`（パスに `{d, o:true, w:太さ}`）、スケッチブック場面は `paper(sc)` のあと `ink`（chalk と同じ引数）、`sketch(sc, x, y, w, h, [パス], 秒, かける秒)`、`wash(sc, x, y, w, h, 'パス', '#色', 秒, かける秒, 濃さ)`
- 時間：`at(S, 行, 秒)`＝その場面の何行目（0から。L の行も数える）が始まって何秒後、`mid(S, 行, 割合)`＝その行の途中
- 黒板の大きさ：x 0〜1752、y 0〜752。右上（x 1500 より右、y 90 より上）はロゴがあるので空ける。文字の幅はおよそ「文字数×大きさ」
- 画面の文字は 60分版の「画面の文字」を土台に。数字や面談の言葉を出すときは原稿どおり。面談の話の場面はスケッチブック（paper）にして、簡単な挿絵を1つ
- 最後の場面は「第M章のまとめ」（チェックの印つき）。第4章の最後は次回予告
