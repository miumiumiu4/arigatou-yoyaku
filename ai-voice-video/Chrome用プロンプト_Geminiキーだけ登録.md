# Claude in Chrome に貼るプロンプト（Gemini のキーを1つ登録するだけ・いちばん簡単な版）

貼る場所：**Chrome の Claude**

10/1 に簡単にした。登録するのは `GEMINI_API_KEY` の1行だけ。
モデル名は Claude Code が自動で選び、声は初期値（語り手 Charon、聞き手 Leda）で作る。声の聞き比べは、動画ができてから Claude Code が見本を作って三浦さんが耳で選ぶ。

```
Gemini の APIキーを、Claude Code の作業環境に1つ登録するのを手伝ってください。
私は初心者です。1つずつ、どこを押せばいいかを教えて、私が終わるのを待ってから次に進んでください。

■ 守ること
・キーの「作成」「コピー」「貼り付け」は私（三浦）がやります。あなたはボタンや入力欄の場所を教えるだけにしてください
・キーの文字列を読んだり、書き写したり、報告に書いたりしないでください
・お金がかかる操作（購入・プラン変更・請求先の変更）はしないでください

■ 1. キーをコピーする
1. 新しいタブで https://aistudio.google.com/apikey を開く
2. キーの一覧の中から、20ドルを払ったプロジェクトのキーを探す（「Paid」「有料」などと出ているもの）。見つからなければ、一覧の様子を教えて止まる
3. キーがなければ「Create API key」（APIキーを作成）ボタンの場所を教えて止まる → 私が押して作る
4. そのキーの「コピー」ボタン（四角が2つ重なったマーク）の場所を教えて止まる → 私がコピーする

■ 2. Claude Code に貼る
1. 新しいタブで https://claude.ai/code を開く
2. 左の一覧から、セッション「三浦のAI音声生成」を開く

4. 「Environment variables」（環境変数）の入力欄を見つけて、場所を教えて止まる
5. 私がそこに、次の1行を入力します（=の右側は、さっきコピーしたキーを貼り付け）
   GEMINI_API_KEY=
6. 「Save」（保存）ボタンの場所を教えて止まる → 私が押す

■ 3. 最後に、私に次のことを教えてください
・キーが「有料（Paid）」のプロジェクトのものだったか
・保存できたか
```
