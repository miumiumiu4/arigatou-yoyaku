## 0. 全体像（お客さんの道）

```
YouTube 30分動画 ─ 最後40秒「止まり方診断へ」 ─┐
YouTube ショート ─ 最後4秒「診断やろうね」 ────┤
                                              ▼
            止まり方診断  miumiumiu4.github.io/shindan/?lesson=1&src=youtube
            （スマホ3分・鍵なし・今日の点数＝スタート地点）
                                              ▼
            結果ページ＋メール：「この点数はスタート地点。第2回・第3回（無料）を見て答え直すと、変化が線になる」

                                              ▼
            第1回（無料4本）→ メール → 第2回・第3回（無料会員サイト）→ 各回の終わりに答え直す（?lesson=2, 3）
                                              ▼
            第4〜7回（11/16〜 販売）→ 7回で「自分の線」ができる → 集客戦略会議
```

例え：YouTubeは「体組成計に初めて乗る日」。1回目の数字は良い悪いではなく「スタート地点」。講座を見るたびに乗り直すから、線になる。だから動画の最後は「売り込み」ではなく「まず1回、計ってみよう」で終える。

### 決めた前提（三浦さん不在のため、ここで決めた）
| 項目 | 決めたこと | 理由 |
|---|---|---|
| YouTubeからの診断リンク | `https://miumiumiu4.github.io/shindan/?lesson=1&src=youtube` | lesson=1 にすると、この答えが「第1回の印」として保存され、講座の第2回で答え直したときに横に並ぶ。src=youtube で「来た場所」が分かる |
| 30分動画の差し込み位置 | **動画の末尾に結合**（「明日のテーマ」のあと） | 書き出し済みのmp4を作り直さずに済む。ep015以降の新しい台本では「今日からできること」と「明日のテーマ」の間に入れる |
| 差し替えの対象 | 未公開で、公開時刻まで**3時間以上**ある動画は、アップ済みでも消して上げ直す。3時間未満（今夜20:00の第2話）は動画そのまま、説明欄と固定コメントだけ | YouTubeはアップ済みの動画ファイルを差し替えられない。消して上げ直すと動画IDが変わるが、未公開なのでどこにも貼られていない |
| ショートの差し込み | 末尾に4秒の終わりカード＋ひとこと。未公開分は全部（#004〜）。今夜19:00の#003は説明欄だけ | 同上 |
| 固定コメント | トークンに書き込み権限が無ければ付けない（説明欄だけで足りる） | 再ログインと権限追加が要る作業は三浦さん不在ではできない |

## 1. 30分動画の末尾クリップ（約45秒・1本を全話で共用）

### 画面
- 曜日の見た目に合わせなくてよい。共通1枚：左に診断ページのスマホ画面（棒グラフの結果画面の録画、または静止画）、右に **QRコード**（ever-video/診断QR_YouTube用.png）と文字。
- 文字（大きく）：「止まり方診断　スマホで3分」「概要欄のリンクから」。下に小さく `miumiumiu4.github.io/shindan/`。
- 終わり2秒は文字だけ：「まず1回、今日の自分を計る」。
- BGM：なし、または既存の30分動画の締めと同じ静かな曲。

### 台本（読み上げ・約45秒）
```
最後に、ひとつだけ。
概要欄に「止まり方診断」のリンクを置きました。
独立したいのに止まっている理由を、9つの中から点数で見る診断です。スマホで3分で終わります。
答えると、あなたを一番止めているものと、次に見るといい動画が、メールで届きます。
そして、ここからが大事です。
この診断は、1回で終わりません。
無料の講座の第2回、第3回を見たあとに、もう一度答えると、前の自分と、今の自分が、横に並んで出ます。
筋トレの体組成計と同じで、計るから、変わったのが分かります。
今日の点数が、あなたのスタート地点です。
まず1回、今日の自分を計ってみてください。
```

### 説明欄に足す文（「▼第1回はこちらから」のリンクの**すぐ下**に入れる）
```
▼止まり方診断（スマホで3分・無料）
https://miumiumiu4.github.io/shindan/?lesson=1&src=youtube
独立したいのに止まっている理由を、9つの中から点数で見る診断です。
講座の第2回・第3回を見たあとに答え直すと、前の自分と並んで変化が見えます。
```
- チャプター：末尾に `MM:SS 止まり方診断のご案内`（MM:SSは元の動画の長さ。ffprobeで取る）。
- 固定コメント（権限があれば）：上の4行をそのまま。

## 2. ショートの終わりカード（4秒・3種類を順番に）

### 画面
縦画面の下3分の1に黒帯、白文字で「止まり方診断 ▶ 概要欄」、右にQR（小さく、スマホでは読めなくてよい。読む人は概要欄から）。上3分の2は直前の最後のフレームを静止で残す。

### ひとこと（読み上げ・各4秒。番号を3で割った余りで回す）
```
A（余り1）：概要欄の診断、やってみてね。3分で、今の自分がわかります。
B（余り2）：止まり方診断、やろうね。概要欄から、スマホで3分です。
C（余り0）：今の自分を、計ってみよう。概要欄の診断から。
```
※ ショート台本（youtube-optin/オリジナルショート台本_30本.md）の「締めの案内は台本に入れない」は、この4秒カードで置き換える。

### 概要欄に足す文（「▼受け取りはこちら」のリンクの**すぐ下**）
```
▼止まり方診断（スマホで3分）
https://miumiumiu4.github.io/shindan/?lesson=1&src=youtube
```
→ youtube-optin/ショート投稿予定表.csv と Mac video/shorts/ショート投稿予定表.csv の「概要欄」列を、#004 以降すべて直す（#001〜#003は公開済みか今夜なので動画はそのまま。#003の説明欄は上げ直さず Studio で足してもよい）。

### 対象
- アップ済み（10/21〜10/23 の #004〜#009）：消して、終わりカード付きで上げ直し（予約時刻は同じ）。
- 未アップ（#010〜#090）：shorts/ のmp4に終わりカードを結合してから、毎朝6時の自動予約に乗せる。
- 長さ：56秒＋4秒＝60秒前後。YouTubeショートは3分まで可なので超えても問題ないが、元が58秒以上のものはカードを3秒にする。

## 4. 自動化（Mac ~/claude/ever-offer/video/）

| # | 作るもの | 中身 |
|---|---|---|
| 1 | `outro/make_outro.py` | 1章の台本から声（既存のリアルボイス設定）＋画面（QR＋文字）を作り `outro/outro_long.mp4`（1920×1080、既存の30分動画と同じfps・音量）。ショート用は `outro/make_short_card.py` で A/B/C の3本 `outro/short_A.mp4` 等（1080×1920、4秒） |
| 2 | `longform/append_outro.py epNNN` | `out/epNNN.mp4` を `out/orig/` に退避し、outro を ffmpeg concat で末尾に結合して `out/epNNN.mp4` を上書き。チャプター用に元の長さを `posts/epNNN.outro.json` に書く |
| 3 | `longform/make_post.py` | 説明欄に1章の4行（第1回リンクの直下）とチャプター末尾の1行を足す。`do_ep.sh` は concat のあとに `append_outro.py` を呼んでから `make_post.py` |
| 4 | `longform/reupload.py epNNN` | result.json があり publishAt まで3時間以上なら、YouTubeの動画を削除→クリップ付きで再アップ（同じ publishAt・タイトル・サムネ）→ result.json を更新。3時間未満なら説明欄だけ更新（権限が無ければ YouTube Studio で手作業、その旨をログに） |
| 5 | `shorts/add_endcard.py` | shorts/*.mp4 の未公開分に A/B/C を結合（元は shorts/orig/ に退避）。CSVの概要欄列も書き換え |
| 6 | `shorts/reupload.py` | uploaded.json の未公開分（公開まで3時間以上）を削除→終わりカード付きで再アップ（同じ予約時刻）。uploaded.json を更新 |
| 7 | 毎朝の自動予約（yt_shorts_daily.py 6:00、yt_long_daily.py 6:10） | 変更なし。上の2・5が先に走っていれば、そのまま終わりカード付きが上がる |

削除→再アップは、公開前の動画だけ。公開済み（第1話、ショート#001〜#003）は触らない。
作業ログは HANDOFF.md に「何本を上げ直したか、動画IDの新旧」を残す（youtube-longform/第NNN話_投稿情報.md のURLも更新）。
