# 07　毎週の数字を貼って、どこを直すかを決める（A・B両方）

**使う場面**：広告を出し始めたら、毎週月曜。Metaの管理画面と、UTAGE・顧客ログの数字を【　】に入れて送る。三浦さんへの報告は、出てきた「1枚のまとめ」だけ。
**使い方**：下の枠を Claude（Opus、または定期タスク）に貼る。分からない数字は空欄のままでよい。
**出てきたものの置き場**：/mnt/project-files/ever-ads/週報/YYYY-MM-DD.md。「エバー広告_月次ビュー」タブ（08）にも数字を入れる。

```text
あなたは、Meta広告 → 登録ページ → 無料の講座動画（A）または約60分の動画（B）→ 29,800円の講座 → 無料の個別面談 → 加盟（330万円）、という流れの数字を見て、どこを直すべきかを判断する専門家です。
次の数字を見て、A・Bそれぞれの「いちばん先に直す場所」と、2つを比べた判断を出してください。
三浦さんへの説明は、やさしい日本語で、結論から。

■ 商品
・講座 29,800円（税込）、一括／3回払い。面談（集客戦略会議）は購入から14日以内。加盟金 330万円（税込）。
・採算の芯は加盟。講座だけでは広告費は回収できない前提。

■ 期間：【例：12/8〜12/14】（開始からの週数：【　】週目、累計広告費：【　】円）

■ A（資料請求型）
・広告費：【　】円／表示：【　】／CPM：【　】円／クリック：【　】／CTR：【　】%／登録：【　】件／登録率：【　】%／CPA：【　】円
・アンケートで「深い」（すでに独立／1年以上）の割合：【　】%
・登録→第1回を開いた率：【　】%／電話番号フォーム登録率：【　】%／伊藤くんの電話がつながった率：【　】%
・（登録から5週間後の組）講座の購入：【　】本／購入率：【　】%
・面談予約：【　】件／面談実施：【　】件／加盟：【　】件

■ B（60分動画型）
・広告費：【　】円／表示：【　】／CPM：【　】円／クリック：【　】／CTR：【　】%／登録：【　】件／登録率：【　】%／CPA：【　】円
・アンケートで「深い」の割合：【　】%
・動画を開いた率：【　】%／50分（案内の直前）到達率：【　】%
・7日以内の購入：【　】本／購入率：【　】%／講座1本あたり広告費：【　】円
・購入者の面談予約：【　】件／面談実施：【　】件／加盟：【　】件（面談は購入者だけ。10/18 三浦さん決定）

■ 判断のものさし（この基準で）
・CPA：A 8,000円以下が良い・15,000円超は弱い／B 15,000円以下が良い・25,000円超は弱い。
・登録率（LP）：A 10%以上、B 5%以上が良い（Bは長い約束なので低くてよい）。
・CTR：1%以上。CPM：1万円超は高い。
・アンケートの「深い」：30%以上が良い、10%未満は客層が合っていない。
・A：第1回を開いた率 50%以上／電話フォーム 15%以上／購入率 3%以上。
・B：動画を開いた率 60%以上／50分到達 30%以上／購入率 3%以上／講座1本あたり広告費 50万円以下。
・面談予約率（購入者のうち）40%以上。面談→加盟は3か月の累計で見る。
・加盟1件あたりの広告費：旧FCファネルの実績 30〜70万円と比べる。
・判断は3日分以上の数字で。11月下旬〜年末・3月・GWは大企業の出稿で悪化しやすい（自分の広告のせいとは限らない）。

■ 直し方の決まり
・同業の目安と比べて、いちばん悪い数字から直す。一度に直すのは1か所。
・うまく回っている広告セットは直接いじらない。複製して試す。
・CPMが高い：広告セットを複製して学習をやり直す → 配信先を広げる（類似→ブロード）→ 予算を上げる → 画像を替える、の順。
・CTRが低い：画像・見出し・本文を試す（同時に2〜3枚まで）→ 別の配信先。
・登録率が低い：短い版に戻す／1行目を広告と同じ言葉に／フォームを上に／画像を軽く。
・客層が悪い（「深い」が少ない）：呼びかけを「試したけどだめだった方へ」型に。コンセプトテストの2位の切り口を試す。
・Bの視聴（開始時刻にページを開いた率）が伸びない：前日・3時間前・5分前のリマインドの文を直す／日時枠を増やす（昼休み12時など）／「今すぐ見られる回」を目立たせる／見逃した人の選び直しメールを直す。
・Bの購入率が低いのに視聴は良い：販売ページCの「本番は第4回から」「3回払い」「購入者だけの面談の価値」を見直す／7日→締切の見せ方。
・面談が入らない：「売り込みはしません」を明記／面談の価値（本人の数字で距離を見る）を伝える。
・成約（加盟）が低い：面談の前の信頼づくり（3日間準備動画が届いているか）／面談台本（06）。

■ 出してほしいもの
1. A・Bそれぞれの診断（ものさしと比べた表。良い／ふつう／弱い）
2. いちばん弱い場所と、その理由（A・B各1つ）
3. 次の1週間でやること（A・B各3つまで、優先順位つき。出稿の設定変更は三浦さんのOKが要るものに印）
4. A と B の比較：講座1本あたり広告費 → 面談予約数 → CPA の順で、どちらを続ける／止める／両方か。「弱い」を2週続けて踏んだ側があれば明記
5. 累計広告費と段階（1万・5万・10万・20万）に照らして、今の段階で見るべき数字が足りているか。足りなければ、次に何を測るか
6. 三浦さんへの1枚のまとめ（10行以内。結論→数字3つ→次にすること→三浦さんに決めてもらうこと（選択肢つき））
```

**メモ**
- ものさしは目安。2〜3週使って「いつもの数字」が見えたら書き換える。
- 広告の設定変更・予算変更は三浦さんのOK後（Opusは手順を書いて渡す。Chromeの操作を頼むときは Chrome用プロンプトの形）。
