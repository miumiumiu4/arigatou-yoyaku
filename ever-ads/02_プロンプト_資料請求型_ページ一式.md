# 02　ファネルA（資料請求型）のページ一式：登録ページ（短い版・長い版）・サンクスページ・アンケート3問・フォーム文言

**使う場面**：コンセプトテスト（01）で切り口が決まったあと。決まる前でも、第一候補の切り口で下書きを作ってよい（あとで1行目だけ差し替える）。
**使い方**：下の枠を Claude（Opus）に貼る。【切り口】だけ埋める。
**出てきたものの置き場**：/mnt/project-files/ever-ads/制作/02_A_登録ページ_短い版.md、02_A_登録ページ_長い版.md、02_A_サンクスページ.md、02_A_アンケート.md
**UTAGEへの反映**：08の手順書。本文18px以上、スマホとPCを別々に確認。

```text
あなたは、広告から来た人に登録してもらうページを書くのが得意なコピーライターです。
次の情報で、登録ページ（短い版・長い版）・サンクスページ・登録直後のアンケートを作ってください。
文体は、やさしい日本語、結論から、一文を短く。あおらない。

■ 情報
・一行のコンセプト：独立できない理由は、お金でも時期でもなかった
・呼びかけ文（広告と同じにする）：【01で勝った切り口の呼びかけ。例：「独立したいと思ってから、もう1年以上たっている方へ」】
・広告で使った見出しと本文：【01の本番広告A】
・登録するともらえるもの：有料講座「エアコン清掃 独立準備講座（全7回・29,800円）」の第1回（4本・約44分）を登録直後に。三浦の音声（約○分、台本 audio-1-3-script.md の長さに合わせる）。第2回・第3回は、電話番号を入れると見られる（講座のご案内のため、担当者からお電話することがある）。
・その先の流れ：メールで、面談で出会った人たちの話と考え方が届く（0〜14日目は毎日、その後は週3通）。約4週間後に講座（第4〜7回）の案内が7日間だけ届く。
・話し手：三浦公嗣（ありがとうグループ代表）。事実（すべて本人の実績で同じ結果の約束ではない。売上は利益ではない）：会社員7か月 → 2019年8月に一人で開業、1台5,000円 → 初月の売上 約100万円 → 年商 約800万→約4,300万→約1億→今 約1.3億円 → 今は現場に出ず会社を経営。2017年に心筋梗塞。開業時に生まれたばかりの息子。
・お客様の声：使わない（公開の了解が取れている「声」はまだ無い。枠だけ作って「※ご本人の体験です。同じ結果をお約束するものではありません」の文を用意しておく）。
・読者は2種類：独立を考えて止まっている会社員／すでに一人で現場に出ている人。どちらも排除しない。「未経験」「副業」「資料を読んで」前提の言い方はしない。
・書いてはいけないこと：加盟募集の言葉（加盟者募集、FC、フランチャイズ）、人名（三浦以外）・地名・屋号・集客サイト名・本の名前、「必ず」「誰でも」「ほったらかし」、期間つきの成果の約束、公式の数字以外の数字、「今だけ」（仕組みで閉じないので）。
・無料のトイレ掃除に触れるなら「トイレ掃除無料」とだけ。始まりは「家族のケンカを減らしたい」。集客はあとから。

■ 登録ページ（短い版）＝最初に出すもの（審査が通りやすい）
1. 呼びかけ文（いちばん上、広告と同じ言葉）
2. キャッチコピー：「独立できない理由は、お金でも時期でもなかった」を芯に、ビフォー→アフターを1〜2行で
3. 登録でもらえるもの（第1回4本＋音声。「有料講座の最初の3回を、そのまま見られます」）
4. 登録フォーム（メールアドレス必須、お名前は任意）＋ボタン「第1回を今すぐ見る（無料）」
5. 三浦の一言プロフィール（2行）と写真の指示
6. 小さく：いつでも1クリックで配信を止められます／成果を保証するものではありません

■ 登録ページ（長い版）＝審査が通ったあとに試す
1. 呼びかけ文
2. キャッチコピー
3. 登録ボタン（画面の一番上でも押せるように）
4. 登録するともらえるものと、見るとどうなるか（第1回の4つの章の題と、見終わったら何が分かるか）
5. 「こんな状態ではありませんか？」の箇条書き（5〜7個。面談で実際に出た言葉を一字も変えずに使う）
6. お客様の声の枠（今は空。見出しだけ）
7. 三浦の紹介と、この悩みの解決に関係する実績だけ（事実＋「約束ではない」）
8. 物語：会社員のころの不安 → 心筋梗塞 → 開業 → 初月 → 「一人で、抱えなくていい」に気づくまで（朝から夜の場面が浮かぶように。ただし出典のない現場の描写は書かない）
9. 手軽さ：「○○は不要です」を3つ（例：新しい資格は不要／今の仕事を辞める必要はまだない／資料を全部読む必要はない）。事実の範囲で
10. 登録すると分かること（箇条書き）
11. 登録フォームと、保証しない旨の一文

■ サンクスページ（登録直後）
・いちばん上：「登録はまだ完了していません」ではなく、本当のことを書く：「登録できました。第1回はこの下からすぐ見られます」（メールが届かなくても見られるようにURLをここに置く）
・3問のアンケート（下）を、第1回のボタンのすぐ下に。「30秒だけ。あなたに合うメールを送るためです」
・小さく：第2回・第3回の案内は明日のメールで／迷惑メールフォルダの確認
・LINEのボタンは置かない（第1段階）

■ 登録直後のアンケート（3問。UTAGEの読者項目に保存）
・Q1 今の状況（1つ選ぶ）：会社員で独立を考えている／副業で清掃を始めている／すでに独立して一人で現場に出ている／独立してスタッフがいる／そのほか
・Q2 独立（または次の一歩）を考え始めてから：半年未満／半年〜1年／1〜3年／3年以上
・Q3 いま一番止まっている理由（1つ）：お金／時期／自分にできるか／家族／相談相手がいない／そのほか（自由に書く）
→ 失礼にならない聞き方、答えやすい選択肢で。「買えそうかどうか」は Q1・Q2 で読む（Q1がすでに独立／Q2が1年以上、を「深い」と数える）。

■ 第2・3回の電話番号フォーム（既存 noavzGai6bR8）の文言
・ボタンの下に1行：「※講座のご案内のため、担当者からお電話することがあります。」（10/17の改善点A-2）。既存の文を直す案を1つ。

■ 守ること
・広告と同じ言葉・同じ雰囲気で始める。
・あいまいな言葉でぼかさない。
・実績は上の事実だけ。数字には「売上で利益ではない」「約束ではない」を添える。
・画像はJPEG、軽く。読み込みが2〜3秒遅れると閉じる人が増える。
・本文18px以上（UTAGEの決まり）。

■ 出してほしいもの
短い版・長い版・サンクスページ・アンケート・電話フォームの文言を、見出しごとに分けて。
最後に、広告（01）との言葉のずれが無いか、書いてはいけない言葉が入っていないかのチェック表。
```
