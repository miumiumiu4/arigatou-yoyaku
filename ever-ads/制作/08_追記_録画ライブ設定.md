## 1. 決まっていること（10/18 三浦さん決定＋08本体）

| 項目 | 中身 |
|---|---|
| 回の時刻 | 毎日 8:00・13:00・20:00＋「今すぐ見られる回」 |
| 選べる範囲 | 今日から3日先まで（始まった回は出さない） |
| 開始 | 開始時刻に自動で始まる。早送りなし |
| チャット欄 | **2019年の三浦のセリフだけ**（名札つき、03_B_チャット風の文.md）。架空の視聴者コメント・視聴人数は出さない |
| 質問欄 | 本物。受け口GAS type=question_b |
| アーカイブ | 終了後、同じページで視聴日から7日間 |
| 講座の締切 | **視聴日から7日後 23:59**（登録日ではない） |
| 見逃した人 | 翌朝 R-5 → 見逃した方のページで日時を選び直す。視聴日時を上書きし、R-1 からやり直す。締切も新しい視聴日から。ただし一度見た人（読者項目「視聴済み」＝最初の視聴日を保存）は締切を動かさない |
| 正直さ | ページとメールに「録画を決まった時刻に配信しています」 |

## 2. Mac で確かめたこと（10/18）

- UTAGEのファネルのページごとに「ウェビナー設定」がある：形式（5択）／長さ／登録の何日後に始めるか／**1日に何回流すか（1回か2回）**／開始〜終了の時刻（2枠）／見逃し配信の日数。
- 「イベント・予約」は Zoom の予約用で、録画を流す機能ではない。
- Facebook リード広告（インスタントフォーム）の連携は無い。

## 3. 要確認と代案

| # | 確かめること | 代案（できなかったとき） |
|---|---|---|
| L1 | ウェビナー設定で **1日3回**（8・13・20時）にできるか。上の確認では「1回か2回」 | ★ページを2枚にする（ページ1＝8時・20時、ページ2＝13時）。または13時を外して 8時・20時の2回（三浦さんに選択肢で聞く） |
| L2 | 登録フォームで視聴日時を選ばせ、読者項目「視聴日時」に入るか（ウェビナー設定の「登録の何日後」との関係） | 読者項目（選択式）で日時を選び、シナリオのリマインダー配信を「視聴日時」基準にする |
| L3 | 「今すぐ見られる回」をウェビナー設定で作れるか（5択の形式の中身） | 同じ動画の通常の視聴ページを1枚作り、R-0 から直接リンク |
| L4 | チャット欄に時刻つきの文を流す設定があるか（表示名「2019年の三浦」） | ★チャット欄は作らない（動画の中の名札と字幕だけ）。作り物の欄を別の方法で足さない |
| L5 | 質問欄を受け口GASへ送れるか | ページ下に普通のフォーム（type=question_b） |
| L6 | 販売ページCの表示期限を「視聴日時」基準にできるか | R-4 のタイミングで配信基準日を視聴日に更新するアクション（08本体 #9） |
| L7 | 選び直したとき、古い視聴日時のリマインドが残らないか | 選び直しで一度シナリオから外して入れ直す |

## 4. 通しテストに足すこと（08-5 の B に追加）

1. 今日の一番近い回を選んで登録 → 待ち画面とカウントダウンが選んだ時刻か。
2. R-1（前日18:00）・R-2（3時間前）・R-3（5分前）が届くか。開始時刻に動画が出て、早送りできないか。
3. チャット欄（作った場合）に「2019年の三浦」の名札で、動画と同じ時刻に文が出るか。
4. 質問欄 → 顧客ログの events に question_b が入るか。
5. 終了2時間後に R-4、販売ページCのカウントダウンが「視聴日から7日後 23:59」か。
6. 開始時刻に開かなかった人に翌朝 R-5 → 選び直し → 新しい日時で R-1 から届き、古い分が届かないか。締切も新しい視聴日からになるか。一度見た人が選び直しても締切が動かないか。
7. 「今すぐ見られる回」を選ぶと R-1〜R-3 が来ず、すぐ見られるか。
