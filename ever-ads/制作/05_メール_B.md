## 視聴日から7日間の締切と、UTAGEの表示期限の整合

| 項目 | 日時（視聴日＝0日目） | 合っているか |
|---|---|---|
| 販売ページCの表示期限 | 視聴日から7日後 23:59 | 基準（読者項目「視聴日時」から。できなければ R-4 で配信基準日を視聴日に更新するアクション、08 #9） |
| カウントダウン | 視聴日から7日後 23:59 | 同じにする |
| R-4「今日から7日目の23時59分まで」 | 7日目 23:59 | 合う |
| B-1〜B-4「動画を見た日から7日目の23時59分まで」 | 7日目 23:59 | 合う |
| B-5（6日目 7:00）「明日の23時59分」 | 7日目 23:59 | 合う |
| B-6a（7日目 7:00）・B-6b（7日目 20:00）「本日23時59分」 | 7日目 23:59 | 合う |
| B-7（8日目 7:00） | 期限の後 | 合う（ページCは受付終了ページへ） |
| 視聴日を選び直した人 | 新しい視聴日が基準。R-1 からやり直し、B-1〜B-7 も新しい視聴日から | まだ見ていない人だけが対象。一度見た人（読者項目「視聴済み」あり）は選び直しても締切を動かさない。7日間の締切が本当の締切であり続けるため |
| 選んだ日に見ず、選び直しもしない人 | 選んだ視聴日が基準のまま（B-1〜は送る） | 合う。R-5 で選び直しを1回だけ案内 |
| 「今すぐ見られる回」 | 視聴日＝登録日。R-1〜R-3 は送らない | 合う |
| 気をつけること | UTAGEの「○日後」が視聴時刻からか、視聴日の0時からかで、23:59 が1日ずれることがある | 通しテスト（08-5）で、試しアドレスの視聴日時とページの非表示の時刻を実際に見て確かめる |
