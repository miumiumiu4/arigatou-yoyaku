# 06　集客戦略会議（個別面談）の台本：広告から来た人向けの差分

**使う場面**：A・Bから来た人が集客戦略会議（Zoom 60分）に来るようになったら。既存の台本（購入者向け。加盟金330万円を最初に正直に伝える形）に、広告経由の人の違いを足す。
**違い**：①来るのは講座の購入者だけ（10/18 三浦さん決定。「買う前に面談」の入口は置かない）②登録から面談までが短い（1〜2週間。エバーの読者は3年の教育を前提にしている）③すでに現場に出ている人の割合が高い見込み ④アンケート11問は予約時に答えている。
**使い方**：下の枠を Claude（Opus）に貼る。既存の台本（Mac ~/claude/ever-offer/集客戦略会議/）を「■ 既存の台本」に貼ってから送る。
**出てきたものの置き場**：/mnt/project-files/ever-ads/制作/06_面談台本_広告経由差分.md

```text
あなたは、高額商品（数百万円）の個別面談で、相手が納得して自分で決められるように導く、誠実なセールスコーチです。
既存の面談台本に、「広告から来た人」向けの差分を作ってください。売り込まない。急かさない。合わない人には早めに正直に伝える。

■ 既存の台本
【ここに貼る】

■ 面談の決まり（変えない）
・最初に加盟金330万円（税込）を正直に伝える（伏せたまま進めない）。
・加盟は無理にすすめない。講座は「加盟をすすめるためのものではない」。
・お金で止まる人には、分割・融資の申請サポートの案内。
・加盟で手に入るもの（確定）：未経験から一人で現場に出られるまでの研修／集客と口コミの型／求人と採用の型／教育とマインドセットの型／お客様向けのメールで短い期間にご予約を集めるマーケティングの型／独立後に相談できる本部と仲間／融資の申請資料のサポート。
・研修の流れ：オンライン研修 → 実務研修1日 → 現場研修15現場 → 最後の3〜5現場は一人 → 5点の口コミ3件。1〜3か月。
・数字は公式の確定だけ。「売上で利益ではない」「約束ではない」。
・人名・地名・屋号・本の名前は出さない。

■ 広告から来た人の違い
1. 購入してすぐ面談を予約した人（第4〜7回をまだ見ていない）：講座のどこを先に見てもらうか。面談の中で講座の中身をどこまで話すか。
2. 登録から面談まで1〜2週間：三浦の話を60分の動画（＋第1〜3回）でしか知らない。信頼の土台が薄い。面談の最初の10分で何を聞き、何を話すか。
3. すでに現場に出ている人が多い見込み：「一人の上限（1日3件・月60〜70件）」「人を育てる」「口コミ20件」の話が中心になる。未経験の人向けの流れ（研修）は聞かれたら。
4. アンケート11問の答えを面談前に読む：「断る理由」が先に出ている。どの答えなら、どう切り出すか（例：「お金」→ 分割・融資の話を先に／「家族」→ 家族と話す時間を取る提案／「自分にできるか」→ 研修の流れと口コミの基準）。
5. 3日間準備動画（予約者に自動で届く）の宿題の答えが来ている場合：その答え（目標年商・集客の穴・使ってよいお金）をどう使うか。

■ 出してほしいもの
1. 既存の台本に差し込む形で、「広告から来た人」用の追加・変更箇所（どの場面の前後に、何を話すか）
2. 最初の10分の話す言葉（講座を買っている人／買っていない人の2通り）
3. アンケートの答え別の切り出し方（11問のうち、断る理由に当たる答えごと）
4. 「この人には今はすすめないほうがいい」目安（広告経由ならではのもの：登録から短い、動画を半分しか見ていない、など）
5. 面談後に送るメッセージ（講座を買っていない人用。加盟に進む人／進まない人／講座だけ買う人の3通り）
```

**メモ**
- 面談は今は三浦さんだけが担当。来るのは購入者だけなので枠は足りる見込み（11/23に売れた数を見て足す）。
