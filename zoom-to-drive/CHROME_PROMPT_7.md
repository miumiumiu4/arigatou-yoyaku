# Claude in Chrome 用 プロンプト⑦（GitHubの編集画面から続ける）

下の枠の中を丸ごとコピーして、Chrome のチャットに貼ってください。

````
依頼元：Claude Code（セッション https://claude.ai/code/session_01HWKWMC1xf7xFB1k72NxABC）
目的：GitHub の Probe.gs のコードを Apps Script の Probe.gs に貼り替えて、関数 probeArchives を実行し、ログを報告する
戻し方：最後の「報告」を埋めて、公嗣さんが Claude Code のセッションに貼り戻す

■ いまの画面
GitHub の Probe.gs が「編集モード（Edit）」で開いている。右上に「Cancel changes」と緑の「Commit changes...」がある画面。

■ ルール
・GitHub では「Commit changes...」（変更を保存）を絶対に押さない。GitHub のコードは書き換えない
・Apps Script の「コード.gs（Code.gs）」は触らない。触るのは「Probe.gs」だけ
・コピーするのはプログラムのコードだけ。秘密の値（APIキー・Client Secret など）は扱わない
・許可画面が出たら押さずに止まって、公嗣さんに頼む
・ログに会議UUID・メールアドレス・人の名前・会話の文章が出たら「＊＊＊」に伏せて報告する
・途中で操作が止められた・できないときは、そこで止まって「どの手順の何で止まったか」を報告する

■ 手順

【1】GitHub の編集モードを抜ける
1. 右上の「Cancel changes」（変更をやめる）を押す。確認が出たら「Discard」や「OK」（破棄）を選ぶ
2. 普通の表示（Code / Blame のタブがある画面）に戻ったことを確かめる。「Commit changes...」は押さない

【2】コードをコピーする
3. コードの枠の右上にある「Raw」の右隣の、四角が2つ重なったボタン（Copy raw file＝ファイルの中身をコピー）を押す
   ※ うまくいかない場合は「Raw」を押して、白い画面で全選択→コピーする
4. 一番上が「/**」、全部で114行のコードであることを確かめる

【3】Apps Script に貼る
5. Apps Script「Zoom書き起こし保存」のタブに切り替える（無ければ script.google.com のマイプロジェクトから開く）
6. 左のファイル一覧で「Probe.gs」を開く（コード.gs ではない）
7. コードの中をクリック → 全選択 → 貼り付けて中身を置き換える
8. 先頭が「/**」であることを確かめて、保存する（⌘＋S またはフロッピーのマーク）
9. 上の関数の欄（▼）を開き、「probeMyNotes」と「probeArchives」の両方が並んでいることを確かめる

【4】実行する
10. 関数の欄で「probeArchives」を選び、表示が切り替わったことを目で確かめる
11. 「▷ 実行」を押す。許可画面が出たら止まって公嗣さんに頼む
12. 「実行完了」が出たら、実行ログを上から下まで全部記録する

■ 報告（最後にこの形で、コードブロックの中に書く）
```
【保管庫 聞き方 試し 報告】
1 GitHub：編集を取り消した＝（済/未）、Commit は押していない＝（はい）
2 Probe.gs 差し替え＝（済/未）、関数2つが並んでいる＝（はい/いいえ）
3 probeArchives：実行＝（済/未）、許可画面＝（出た/出なかった）、ログ＝（全行。伏せた所は＊＊＊）
止まった所・質問：
未確認のもの：
```
````
