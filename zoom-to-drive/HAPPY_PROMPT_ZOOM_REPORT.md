# HAPPY に渡すプロンプト（Zoom が終わるたびの報告と、個別コンサル動画のメール送付）

````
■ 依頼元と戻し先
・依頼元：Claude Code のスレッド「✅Zoom書き起こし → ドライブ自動保存」 https://claude.ai/code/session_01HWKWMC1xf7xFB1k72NxABC
・関係する作業フォルダ：GitHub miumiumiu4/arigatou-yoyaku（ブランチ claude/stoic-volta-24mepa、フォルダ zoom-to-drive・consult-routine）／Mac ~/claude/zoom-auto（Zoom録画→YouTube の自動アップ）
・関係する Google ドライブのフォルダ：「Zoom書き起こし」（元の書き起こし）「Zoom書き起こし_清書」（清書）「個別コンサル_自動作成」（振り返り・台本）

■ 目的（三浦さんの言葉）
Zoom が終わるたびに、次の2つがちゃんとできたことを、HAPPY から三浦さんに報告してほしい。
 ① Claude が Zoom の書き起こしを清書して、ドライブ「Zoom書き起こし_清書」に入れたこと
 ② Zoom の録画を YouTube に「限定公開」でアップしたこと
さらに、個別コンサル（松本さん・向井さん・秋元さん）の録画は、アップしたあとに、受けた本人へ Gmail でリンクを自動で送る。

■ 今の仕組み（分担）
・書き起こしの保存：Apps Script「Zoom書き起こし保存」が1時間ごとに「Zoom書き起こし」へ保存
・清書・振り返り：Claude Code の毎晩の自動作業（23:48ごろ）が「Zoom書き起こし_清書」へ清書を作る。個別コンサルは振り返りページ・台本も作る
・YouTube：Mac の ~/claude/zoom-auto（zoom_auto.py）が限定公開でアップ（2本に分かれた録画も対応済み）

■ やってほしいこと
1. 報告の置き場所を1つ作る
   ・GitHub の非公開リポジトリ miumiumiu4/arigatou に Issue「Zoom処理の報告（自動）」を1つ作る
   ・公開リポジトリ（arigatou-yoyaku）には書かない。限定公開の YouTube リンクが誰でも見られてしまうため
2. YouTube 側の報告
   ・zoom_auto.py が1本上げるたびに、その Issue にコメントを1つ足す
   ・コメントの形：「【YouTube】2026-10-31 20:03 松本さんzoom｜限定公開｜（URL）」
   ・失敗したときも「【YouTube 失敗】日時・会議名・エラーの1行」を書く
3. 清書側の報告
   ・Claude Code の毎晩の自動作業が、清書を作るたびに同じ Issue にコメントするようにしたい
   ・ただ今は、Claude Code のクラウドのスレッドから非公開リポジトリ arigatou に書く権限がない
   ・三浦さんが、このスレッドに arigatou を足すことを許可する必要がある
   ・それまでは HAPPY が毎朝、ドライブ「Zoom書き起こし」と「Zoom書き起こし_清書」を見比べて、清書の済み・未を確かめる
4. 三浦さんへの報告
   ・Zoom が終わったあと、清書（翌晩）と YouTube の両方がそろったら、三浦さんに1回だけ報告する
   ・報告の形：「✅ 10/31 20:03 松本さんzoom：清書（ドライブのリンク）／YouTube 限定公開（リンク）」
   ・片方が24時間たっても無ければ「⚠️ ◯◯がまだ」と報告する
5. 個別コンサルの動画を本人へメールする（Gmail）
   ・対象：予定名に「松本」「向井」「秋元」のどれかと「コンサル」、または「松本さんzoom」のような本人との1対1の回
   ・送り先：本人のメールアドレス。HAPPY が三浦さんに1回確かめて、Mac の設定ファイルにだけ置く（GitHub やチャットには書かない）
   ・送る文（三浦さんの名前で出すので「お疲れ様」「無理」は使わない）：「◯◯さん　本日はありがとうございました。今日のコンサルの録画です（限定公開・リンクを知っている人だけ見られます）。（URL）　三浦」
   ・最初の3通は「下書き」に入れて三浦さんが確かめ、OK が出たら自動送信に切り替える
   ・送ったら、Issue に「【メール】日時・会議名・送り先の名前」を書く（アドレスは書かない）
   ・送らないもの：合言葉・パスワード・口座番号が映った・読まれた回は、YouTube を「非公開」にしてメールせず、三浦さんに聞く（該当する回は三浦さんが HAPPY に直接伝える）
6. 過去の書き起こし（ハードディスクの443件）
   ・HAPPY が Mac から Google ドライブ「Zoom書き起こし」の中の新しいフォルダ「HDの過去分_書き起こし」に、テキストのまま上げる
   ・ファイル名は「yyyy-MM-dd_HHmm_会議名」の形にそろえる
   ・上がったら、Claude Code の毎晩の自動作業で1晩に10件ずつ清書する（約45晩）。急ぐなら三浦さんに一言もらって件数を増やす

7. 振り返り動画の声を、毎回 ElevenLabs の「サトシ先生」のリアルボイスにする（三浦さんの指示）
   ・ElevenLabs の鍵は Mac の中だけにある。クラウドの Claude は使えないので、声入れは Mac でやる（前に ~/claude/ever-offer でサトシ先生の声の動画を作ったやり方と同じ）
   ・クラウドの Claude Code は毎晩、個別コンサルの回ごとに、ドライブ「個別コンサル_自動作成」の中に「動画の材料_yyyy-MM-dd_名前さん」フォルダを作り、読み上げ原稿（script.txt。「=== スライドNN：題 ===」で区切ってある）とスライド（slide01.png〜）を入れる
   ・Mac は毎朝そのフォルダを見て、まだ動画が無い回について：
     ① 原稿をスライドごとにサトシ先生の声で読み上げる（速さ0.92）
     ② スライドと音声をつないで動画にする
     ③ YouTube に「限定公開」で上げる
     ④ Issue に「【振り返り動画】日時・名前さん｜（URL）」を書く
   ・HAPPY は三浦さんに「サトシ先生の声の振り返り動画ができました（URL）」と報告する
   ・振り返り動画は三浦さん専用。クライアントにはメールしない
   ・サトシ先生の声の動画ができるまでは、振り返りページの自動の読み上げ動画を仮のものとして使う

■ 守ること
・秘密の値（YouTube・Gmail のログイン情報、合言葉）は画面・ログ・GitHub に出さない
・削除しない。YouTube の公開範囲を「公開」にしない
・クライアントへのメールは5の決まりのとおりだけ

■ 報告（最後にこの形で、「✅Zoom書き起こし → ドライブ自動保存」のスレッドに貼り戻す）
【Zoom報告・メール送付 設定の報告】
1 Issue＝（URL／作れなかった理由）
2 zoom_auto.py のコメント＝（済/未）、試しの1件＝
4 三浦さんへの報告の流れ＝（済/未）
5 メールの送り先の確認＝（済/未）、下書き3通＝（済/未）
6 過去分443件のアップ＝（◯件済/未）、フォルダのID＝
7 サトシ先生の声の振り返り動画＝（仕組み 済/未）、試しの1本＝（URL）
止まった所・質問：
````
