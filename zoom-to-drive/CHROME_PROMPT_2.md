# Claude in Chrome 用 続きのプロンプト（setup・run の実行と My Notes の権限確認）

公嗣さんがスクリプトプロパティの値を貼り終えてから、下の枠の中を丸ごとコピーして、前回と同じ Chrome のチャットに貼ってください。

````
依頼元：Claude Code（セッション https://claude.ai/code/session_01HWKWMC1xf7xFB1k72NxABC）
目的：Zoom書き起こし自動保存の続き。【5】setup と【6】run を実行して動作を確かめる。あわせて My Notes 用の権限が Zoom アプリに出てくるかを見る（追加はしない）
戻し方：最後の「報告」を埋めて、公嗣さんが Claude Code のセッションに貼り戻す

前回の絶対ルールはすべてそのまま守ってください。特に：
・許可画面（OAuth同意画面・「このアプリは Google で確認されていません」など）が出たら、押さずに止まって公嗣さんに頼む
・Client Secret・APIキーなどの値は読まない・書かない。ログに秘密の値が出ていたら、その部分は「＊＊＊」に伏せて報告する
・削除・既存設定の変更の前には止まって確認する
・確認できないものは「未確認」と書く

■ 手順（この順番で）

【4の仕上げ】スクリプトプロパティの保存を確認する
- Apps Script「Zoom書き起こし保存」→ 左の歯車「プロジェクトの設定」
- スクリプト プロパティに次の5つの名前があり、どれも値が入っている（空欄でない）ことだけを確認する。値そのものは読まない
  ZOOM_ACCOUNT_ID / ZOOM_CLIENT_ID / ZOOM_CLIENT_SECRET / ZOOM_USER_EMAIL / ANTHROPIC_API_KEY
- 空欄があれば止まって公嗣さんに伝える。未保存なら「スクリプト プロパティを保存」を押す

【5】setup を実行する
- 左の「<>」エディタ → 上の関数の選択で「setup」→「実行」
- 「承認が必要です」が出たら止まって、公嗣さんに次をお願いする
  「権限を確認」→ アカウント選択 →「詳細」→「Zoom書き起こし保存（安全ではないページ）に移動」→ 許可
- 実行ログに「準備完了。フォルダ: https://drive.google.com/...」が出たか確認し、その行をそのまま報告する
- 左の時計マーク「トリガー」を開き、関数 run・時間主導型・1時間おき のトリガーが「1つだけ」あることを確認する

【6】run を実行する
- エディタに戻り、関数の選択で「run」→「実行」
- 実行ログの「保存: …」の行をすべてそのまま報告する
  ・「保存」が1つも出ずに正常終了した場合は、そのまま「保存0件」と報告する（直近7日にクラウド記録の会議が無ければ0件が正常）
  ・エラーで止まった場合は、エラー文をそのまま報告する（秘密の値は伏せる）
  ・「Claudeでの名前付けに失敗」という行が出た場合も、その行をそのまま報告する（保存自体は予定名で続く）
- Googleドライブで「Zoom書き起こし」フォルダを開き、中のファイル名を最大10件報告する
- ファイルを1つ開き、先頭の「開始」「カレンダーの予定」「Zoom上の話者名」の3行が入っているか確認する（本文の中身は報告しない）

【7】My Notes 用の権限が選べるかを見る（見るだけ。追加しない）
- marketplace.zoom.us → Manage → zoom-to-drive → Scopes →「Add Scopes」を開く
- 検索欄があれば「my_notes」「notes」「docs_archiving」「archiv」で順に検索し、出てきたスコープ名をすべて報告する（例：my_notes:read:note:admin のような名前）。検索欄が無ければ、一覧の中から My Notes / Docs / Archiving に関係する項目名を報告する
- どれにもチェックを付けずに「Cancel」または閉じるで戻る。保存・Done は押さない

■ 報告（最後にこの形で、コードブロックの中に書く）
```
【Zoom書き起こし自動保存 設定報告（続き）】
4 スクリプトプロパティ：5つとも値あり＝（はい/いいえ：空欄の名前）
5 setup：承認＝（済/未）、ログ＝（そのまま）、トリガー＝（run・1時間おき・件数）
6 run：ログ＝（そのまま。保存0件ならそう書く）、フォルダ内のファイル名＝（最大10件）、先頭3行＝（入っていた/なかった/ファイル無し）
7 My Notes関係のスコープ：my_notes＝（出てきた名前を列挙/なし）、docs_archiving＝（同）、その他関係しそうなもの＝
止まった所・質問：
未確認のもの：
```
````
