# Claude in Chrome 用 プロンプト⑨（My Notes の自動保存を始める＝仕上げ）

````
依頼元：Claude Code（セッション https://claude.ai/code/session_01HWKWMC1xf7xFB1k72NxABC）
目的：Zoom の My Notes（要約・メモ・書き起こし）を Google ドライブ「Zoom書き起こし」フォルダへ自動保存し始める。最新の会議から順に保存される
戻し方：最後の「報告」を埋めて、公嗣さんが Claude Code のセッションに貼り戻す

■ ルール
・秘密の値は扱わない（今回は貼る必要なし）
・Chrome の操作が安全チェックで止められたら、その手順は公嗣さんに日本語で1つずつ案内して代わりに押してもらい、次の手順から続ける
・英語のボタンは「英語（日本語の意味）」の形で伝える
・GitHub では「Commit changes」と鉛筆マーク（編集）を押さない
・Apps Script の コード.gs・Probe.gs・Polish.gs は書き換えない。書き換えるのは MyNotes.gs だけ
・許可画面が出たら、押す前に公嗣さんに確認する（承認は公嗣さん本人）
・ログに人の名前・会話の文章が出たら「＊＊＊」に伏せる

■ 手順
【A】MyNotes.gs を新しい版にする
1. https://github.com/miumiumiu4/arigatou-yoyaku/blob/claude/stoic-volta-24mepa/zoom-to-drive/MyNotes.gs を開く。上部が「321 lines」であることを確かめる
2. 「Raw」の右隣の、四角が2つ重なったボタン（Copy raw file＝中身をコピー）でコピーする
3. Apps Script「Zoom書き起こし保存」→ 左の MyNotes.gs を開く → 中身を全部選んで消し、貼る → 保存（フロッピーのマーク）
4. 一番下までスクロールし、最後の行番号が 321 前後であることを確かめる

【B】自動保存を始める
5. 上の関数の欄（▼）で「setupMyNotes」を選び、切り替わったことを確かめて「▷ 実行」
6. 許可画面が出たら、公嗣さんに押してもらう：Review permissions（権限を確認）→ アカウントを選ぶ → Advanced（詳細）→ Go to Zoom書き起こし保存 (unsafe)（安全ではないページに移動）→ Allow（許可）→ もう一度「▷ 実行」
7. 実行ログを最後まで待つ（最大6分）。「保存:」の行の数と、「時間切れ」「失敗」の行があればその文言を記録する（名前は＊＊＊）

【C】ドライブを確かめる
8. Google ドライブで「Zoom書き起こし」フォルダを開き、ファイルの数と、2026-10-11 で始まるファイルがあるか（名前は＊＊＊でよい）を確かめる
9. 左の「トリガー」（目覚まし時計のマーク）に runMyNotes が「1時間おき」で入っているか確かめる

■ 報告（最後にこの形で、コードブロックの中に書く）
【My Notes 仕上げ 報告】
A MyNotes.gs 差し替え＝（済/未）、行数＝
B setupMyNotes＝（実行した/エラー：文言）、「保存:」の行＝＿件、時間切れ・失敗の行＝
C フォルダのファイル数＝＿、2026-10-11 のファイル＝（ある/ない）、トリガー runMyNotes＝（ある/ない）
止まった所・質問：
````
