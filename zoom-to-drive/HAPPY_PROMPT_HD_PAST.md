# HAPPY に渡すプロンプト（Mac mini が届いたら、ハードディスクの過去の書き起こし443件を自動で清書に回す）

````
■ 依頼元と戻し先
・依頼元：Claude Code のスレッド「✅Zoom書き起こし → ドライブ自動保存」 https://claude.ai/code/session_01HWKWMC1xf7xFB1k72NxABC
・関係する作業フォルダ：GitHub miumiumiu4/arigatou-yoyaku（ブランチ claude/stoic-volta-24mepa、フォルダ zoom-to-drive・consult-routine）／Mac mini の ~/claude/hd-past-transcripts（新しく作る）
・関係する Google ドライブのフォルダ：「Zoom書き起こし」（ID 1QaY1uw1dMo80hKD8SmVFUdc5nx8-SWrA）の中に作る「HDの過去分_書き起こし」、清書の置き場所「Zoom書き起こし_清書」

■ 目的
ハードディスクにある過去の Zoom の書き起こし（約443件）を Google ドライブに上げる。
Claude Code の毎晩の自動作業（23:48ごろ）が、1晩10件ずつ清書して「Zoom書き起こし_清書」に入れていく。
Mac mini は 11月2日に届く予定。届いたら三浦さんの手をほとんど使わずに始まるようにしておく。

■ 今やること（11/2 より前）
1. この作業を「Mac mini が届いたらやること」として控えておく
2. 11/2 の朝に三浦さんへ1回だけ声をかける：「Mac mini が届いたら、ハードディスクをつないで『つないだ』と言ってください。あとはこちらで進めます」
3. 三浦さんに聞いておくこと（1回だけ）：
   ・どのハードディスクか
   ・書き起こしが入っているフォルダの場所（分からなければ「分からない」でよい。こちらで探す）

■ 届いてハードディスクがつながったらやること
1. 探す
   ・ハードディスクの中から、Zoom の書き起こしのファイルを探す（.txt・.vtt・.docx・.md など。Zoom の録画フォルダの中の書き起こしも含む）
   ・数・合計サイズ・いちばん古い日付と新しい日付を数える（443件前後のはず）
   ・動画や音声のファイルは上げない（書き起こしの文字だけ）
2. そろえる（ローカルの ~/claude/hd-past-transcripts/ で作業。元のファイルは動かさない・消さない）
   ・ファイル名を「yyyy-MM-dd_HHmm_会議名_HD」にそろえる。日付はファイルの中身か、フォルダ名か、作成日の順で決める。会議名が分からなければ「会議名不明」
   ・中身はテキストにする。形は、今の「Zoom書き起こし」と同じく「HH:MM:SS 話者: 発言」の1行1発言に近づける（できる範囲でよい）
   ・先頭に1行「元のファイル：（ハードディスク上のパス）」を入れる
   ・同じ会議の重複は1つにまとめ、どれをまとめたか一覧に書く
   ・一覧 list.tsv を作る（新しいファイル名、元のパス、日付、行数）
3. 上げる
   ・Google ドライブ「Zoom書き起こし」の中に「HDの過去分_書き起こし」フォルダを作り、2のファイルを Google ドキュメントとして上げる
   ・一度に全部でよい。途中で止まったら、続きから上げ直せるようにする（上げたものを list.tsv に印）
   ・上げたあと、ドライブ上の数と list.tsv の数が合うか確かめる
4. 自動の清書につなぐ
   ・清書は Claude Code の毎晩の自動作業がやる。決まりは consult-routine/ROUTINE_PROMPT.md の手順0（「HDの過去分_書き起こし」を古い順に1晩10件）
   ・HAPPY がやるのは、フォルダが用意できたことの報告だけ
   ・急ぐなら1晩の件数を増やせる（三浦さんの一言で ROUTINE_PROMPT の「10件」を変える）

■ 守ること
・秘密の値（ログイン情報・合言葉・パスワード・口座番号など）を画面・ログ・GitHub に出さない。書き起こしの中身は GitHub に置かない（このリポジトリは公開）
・ハードディスクのファイルは消さない・動かさない・名前を変えない（コピーして作業する）
・ドライブのほかのファイルは変えない。共有の設定も変えない

■ 報告（最後にこの形で、「✅Zoom書き起こし → ドライブ自動保存」のスレッドに貼り戻す）

ドライブ「HDの過去分_書き起こし」のフォルダID＝、上げた数＝、上げられなかった数と理由＝
止まった所・質問：
````
