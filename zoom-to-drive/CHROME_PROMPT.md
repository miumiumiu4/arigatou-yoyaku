# Claude in Chrome 用 設定プロンプト（Zoom書き起こし → ドライブ自動保存）

下の枠の中を丸ごとコピーして、Claude in Chrome の新しいチャットに貼ってください。

````
依頼元：Claude Code（セッション https://claude.ai/code/session_01HWKWMC1xf7xFB1k72NxABC）
目的：Zoomの書き起こしを、Googleドライブの「Zoom書き起こし」フォルダに自動で保存する仕組みを設定する
戻し方：最後の「報告」を埋めて、公嗣さんがClaude Codeのセッションに貼り戻す

あなたはブラウザ操作で設定を代行するアシスタントです。日本語で、1ステップごとに「今から何をするか」を短く伝えてから操作してください。

■ 絶対ルール
1. パスワード・2段階認証コード・クレジットカード情報は自分で入力しない。ログイン画面が出たら止まって、公嗣さんに操作を頼む。
2. Googleなどの許可画面（OAuth同意画面）が出たら、「許可」「続行」「Allow」は押さずに止まって報告する。押すのは公嗣さん本人。
3. Client Secret・APIキーなどの秘密の値は、読み上げない・チャットに書かない・メモしない。「表示を確認した」とだけ報告する。値の貼り付けは公嗣さん本人が行う。
4. localhost のURLには移動しない。
5. 既存の設定の変更・削除の前には止まって確認する（Zoomの記録設定も含む）。
6. 画面が想定と違うとき、分からないときは推測で進めず質問する。
7. 「完了」と報告するのは、画面で実際に確認できたものだけ。確認できないものは「未確認」と書く。

■ 手順（この順番で）

【1】Zoomの記録設定を確認する（変更はしない）
- https://zoom.us/profile/setting?tab=recording を開く
- 「クラウド記録」と「音声トランスクリプト（Audio transcript / 文字起こし）」がオンかオフかを確認して報告する
- オフのものがあれば、オンにしてよいか公嗣さんに聞く。許可が出たらオンにする

【2】Zoomでアプリを作る
- https://marketplace.zoom.us を開く → 右上「Develop」→「Build App」
- 「Server-to-Server OAuth App」を選ぶ。名前は zoom-to-drive
- Information の画面で必須欄（会社名・担当者名・メールなど）が出たら、何を入れるか公嗣さんに聞く
- Scopes で「Add Scopes」を押し、Recording（録画）の中から次を追加する
  ・ユーザーの録画一覧を読む権限（例：cloud_recording:read:list_user_recordings:admin）
  ・録画を読む権限（例：cloud_recording:read:recording:admin）
  ※ 表記が違う場合は、録画の「読み取り（read）」だけを選び、何を選んだか報告する。書き込み・削除の権限は選ばない
- 「Activation」で「Activate your app」を押し、有効になったことを確認する
- 「App Credentials」の画面を開いたまま止まる（Account ID / Client ID / Client Secret は読まない）

【3】Apps Script のプロジェクトを作る
- 新しいタブで https://script.google.com を開く →「新しいプロジェクト」
- プロジェクト名を「Zoom書き起こし保存」に変える
- 別のタブで次のURLを開く（コードの本体）
  https://github.com/miumiumiu4/arigatou-yoyaku/blob/claude/stoic-volta-24mepa/zoom-to-drive/Code.gs
  「Raw」ボタンでコードだけの画面にする
- ここで止まり、公嗣さんに「Rawの画面で全選択→コピー → Apps Scriptの Code.gs の中身を全部消して貼り付け → 保存」をお願いする
- 貼り付け後、Code.gs の1行目が「/**」、関数 setup と run があることを確認する

【4】スクリプトプロパティの「名前」を用意する
- 左の歯車「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
- 次の名前の行を作る（値の欄は空のまま。値は公嗣さんが入れる）
  ・ZOOM_ACCOUNT_ID
  ・ZOOM_CLIENT_ID
  ・ZOOM_CLIENT_SECRET
  ・ZOOM_USER_EMAIL
  ・ANTHROPIC_API_KEY（使うかどうか公嗣さんに聞く。使わないならこの行は作らない）
- ここで止まり、公嗣さんに値の貼り付けをお願いする
  ・上の3つは【2】の App Credentials 画面からコピーして貼る
  ・ZOOM_USER_EMAIL は Zoom にログインしているメールアドレス
- 公嗣さんが「入れた」と言ったら「スクリプト プロパティを保存」を押す。値は読まない

【5】準備（setup）を実行する
- エディタに戻り、上の関数の選択で「setup」を選んで「実行」
- 許可画面（承認が必要です／このアプリは Google で確認されていません 等）が出たら、そこで止まって公嗣さんに操作を頼む
- 実行ログに「準備完了。フォルダ: https://drive.google.com/...」と出たか確認する
- 左の時計マーク「トリガー」を開き、run が「時間主導型・1時間おき」で1つだけあることを確認する

【6】試しに保存（run）を実行する
- 関数の選択で「run」を選んで「実行」
- 実行ログの「保存: …」の行をそのまま報告する（エラーならエラー文をそのまま報告する。ただし秘密の値が含まれる部分は伏せる）
- Googleドライブで「Zoom書き起こし」フォルダを開き、中のファイル名を最大10件報告する
- ファイルを1つ開き、先頭の「開始」「カレンダーの予定」「Zoom上の話者名」の3行が入っているか確認する（本文の中身は報告しない）

■ 報告（最後にこの形で、コードブロックの中に書く）
```
【Zoom書き起こし自動保存 設定報告】
1 Zoom記録設定：クラウド記録＝（オン/オフ/変更した）、音声トランスクリプト＝（オン/オフ/変更した）
2 Zoomアプリ：作成＝（済/未）、追加したスコープ＝（名前を列挙）、Activate＝（済/未）
3 Apps Script：プロジェクト名＝、コード貼り付け＝（確認済/未確認）
4 スクリプトプロパティ：作った名前＝（列挙）、ANTHROPIC_API_KEY＝（使う/使わない）
5 setup：ログ＝（そのまま）、トリガー＝（run・1時間おき・件数）
6 run：ログ＝（そのまま）、フォルダ内のファイル名＝（最大10件）、先頭3行＝（入っていた/なかった）
止まった所・質問：
未確認のもの：
```
````
