# Claude in Chrome 用 プロンプト⑥（公嗣さんが操作し、Chrome が案内と記録をする形）

下の枠の中を丸ごとコピーして、前回と同じ Chrome のチャットに貼ってください。

````
依頼元：Claude Code（セッション https://claude.ai/code/session_01HWKWMC1xf7xFB1k72NxABC）
目的：Probe.gs を差し替えて probeArchives を実行し、会社全体の保管庫（/docs/archives）の正しい聞き方を探す
戻し方：最後の「報告」を埋めて、公嗣さんが Claude Code のセッションに貼り戻す

■ 今回のやり方（大事）
前回・前々回、Chrome が操作すると安全チェックで止められた。なので今回は：
・画面の操作（タブを開く・クリック・コピー・貼り付け・実行）は、すべて公嗣さんが行う
・Chrome は操作しない。画面を見て、次に押す場所を日本語で1つずつ案内し、結果を確かめて記録する
・英語のボタンは「英語（日本語の意味）」の形で伝える
・1つ案内したら、公嗣さんの「できた」を待ってから次に進む
・許可画面が出たら、押す前にどう押すかを案内する（承認は公嗣さん本人）
・ログに会議UUID・メールアドレス・人の名前・会話の文章が出たら「＊＊＊」に伏せて記録する
・Code.gs（コード.gs）は触らないよう案内する

■ 案内する順番

【1】Probe.gs を差し替える
1. 新しいタブを開いて、次のURLを開いてもらう
   https://github.com/miumiumiu4/arigatou-yoyaku/blob/claude/stoic-volta-24mepa/zoom-to-drive/Probe.gs
2. コードの右上の「Raw（コードだけを表示）」を押してもらう
3. 画面の一番上が「/**」で始まっているかを確かめてから、⌘＋A（全選択）→ ⌘＋C（コピー）してもらう
4. Apps Script「Zoom書き起こし保存」のタブに戻り、左の「Probe.gs」を開いてもらう（コード.gs ではない）
5. コードの中をクリック → ⌘＋A → ⌘＋V で貼ってもらう。先頭が「/**」か画面で確かめる
6. ⌘＋S で保存してもらう
7. 上の関数の欄（▼）を押して、「probeMyNotes」と「probeArchives」の2つが並んでいるか画面で確かめる。並んでいなければ 3 からやり直してもらう

【2】probeArchives を実行する
8. 関数の欄で「probeArchives」を選んでもらい、表示が切り替わったことを画面で確かめる
9. 「▷ 実行（Run）」を押してもらう
10. 許可画面が出たら、押し方を案内する：
    Review permissions（権限を確認）→ アカウントを選ぶ → Advanced（詳細）→ Go to Zoom書き起こし保存 (unsafe)（安全ではないページに移動）→ Allow（許可）
11. 「実行完了」が出たら、実行ログを上から下まで全部記録する（画面で読む。足りなければ公嗣さんにスクロールしてもらう）

■ 報告（最後にこの形で、コードブロックの中に書く）
```
【保管庫 聞き方 試し 報告】
1 Probe.gs 差し替え＝（済/未）、関数2つ（probeMyNotes・probeArchives）が並んでいる＝（はい/いいえ）
2 probeArchives：実行＝（済/未）、許可画面＝（出た/出なかった）、ログ＝（全行。伏せた所は＊＊＊）
止まった所・質問：
未確認のもの：
```
````
