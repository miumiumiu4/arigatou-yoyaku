````
依頼元：Claude Code
戻し先：Claude Code のスレッド「✅Zoom書き起こし → ドライブ自動保存」（https://claude.ai/code/session_01HWKWMC1xf7xFB1k72NxABC）
作業フォルダ：GitHub miumiumiu4/arigatou-yoyaku（ブランチ claude/stoic-volta-24mepa）の consult-routine フォルダ

  https://docs.google.com/document/d/1qQ2u-xULa6UJ-HCeaFJVXIsVttVewnoHiM5wvrN8ATk/edit
目的：「0｜前回のおさらい」のメモ欄の空欄（　　）に、10/11 に決まったミッションの一文を入れる。ほかの所は一切変えない

■ ルール
・直すのは下の1か所だけ。ほかの文字・書式は触らない。共有設定は変えない
・英語のボタンは「英語（日本語の意味）」の形で伝える
・Chrome の操作が安全チェックで止められたら、その手順は公嗣さんに日本語で1つずつ案内して代わりに押してもらい、次の手順から続ける

■ 手順
1. 上の対象ファイルのURLを開く
2. 「編集」メニュー →「検索と置換」（Ctrl+H／Mac は ⌘+Shift+H）を開く
3. 「正規表現を使用」にチェックを入れる
4. 「検索」欄に次を入れる：
書き写しておく：（[　 ]*）
5. 「置換後の文字列」欄に、「書き写しておく：」に続けて、Claude Code のスレッドで渡されたミッションの一文をそのまま入れる
   （この指示書は公開の場所に置くので、ミッションの文はここには書かない。10/22 15:00 のカレンダーの説明欄にも同じ文がある）
6. 検索欄の右に「1/1」と出ることを確かめてから「すべて置換」を押す（0件や2件以上なら押さずに止まって報告）
7. 「0｜前回のおさらい」のメモの行を目で見て、ミッションが入ったことを確かめる

■ 報告（最後にこの形で、コードブロックの中に書く。貼り戻す先：Claude Code のスレッド「✅Zoom書き起こし → ドライブ自動保存」）
【10/22台本 ミッション記入 報告】
検索の件数＝（1/1 など）、置換＝（済/未）、目で確認＝（入った/入っていない）
止まった所・質問：
````
