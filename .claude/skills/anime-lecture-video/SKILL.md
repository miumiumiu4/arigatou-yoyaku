# アニメ入り講座動画の作り方（三浦さん用）

2本の解説動画（2026年9月に三浦さんが共有）の中身を、このリポジトリで再現できる形にまとめたもの。
提案するときは「パターン」と「プロンプト」をそのまま使い回し、三浦さんの講座向けに言い換える。

## 0. 前提（決まっていること）

- 声は三浦さん本人の声は使わない。**Google AI Studio の Gemini TTS の用意された声**を借りる（2026年9月30日決定）
- 納品は MP4。色は紺 #1F3A5F とオレンジ #E8833A、ロゴは `ai-voice-video/logo/`
- 既存のスライド型の仕組みは `ai-voice-video/`（`build.py`、`HANDOFF.md`）
- 講座は有料商品。**未公開の台本を AI Studio の無料枠に貼らない**（下の「注意」）

## 1. 2本の動画の要点

### 動画A「Gemini Flash TTS × Claude Opus でAI動画編集（歴史解説）」
流れは「声を選ぶ → 台本と演技指示をClaudeに書かせる → 鳴らして直す → 映像をHTMLで作る → 書き出して音声と重ねる」。
- **Gemini TTS の特徴**：段落ごとに演技（落ち着いて・驚いて等）を文字で指示できる／2人の掛け合いができる／声は2000種類以上。場所は AI Studio の「Generate speech」。ブラウザだけで使え、無料枠で1本は作れた
- **声の選び方**：言語=日本語、雰囲気、使い道（例：チューター＝先生っぽい声）で絞る。同じ一文を3つの声で鳴らして比べ、動画の中身から逆算して決める（解説なら聞き疲れしない落ち着いた声）
- **台本の頼み方**：最初に「Gemini TTS で読ませる台本」と書く。頼む文は4つの塊（何をどのくらい／登場人物の役割／守ること／出力の形＝話者・英語の短い演技指示・セリフを1行ずつ）
- **TTS のくせ3つ**
  1. 読み間違い：固有名詞は**ひらがな**で直る。熟語はひらがなでも直らないことがあり、**言い換え**で直す（例「激突」→「ぶつかります」）。探すときは音声を文字起こしして台本と見比べる。直した読みはメモして使い回す
  2. 間：長い間のタグは効きすぎる（7秒空いた）。間はタグに頼らず、後で音声を切って調整
  3. 掛け合いは**交互に固定**（語り手→聞き手→語り手…）。同じ人が続けて話す部分は1つの塊にまとめる（15行→12塊で一発で通った）
- **映像**：Claude に「HTMLファイル1つで動く映像」を頼む。伝えるのは3つ（見た目を言葉で／**どの言葉が何秒に来るかの一覧**／**秒数を渡すとその瞬間の絵で止まる仕掛け**）。Claude は自分で25か所を画面に書き出して崩れを確認してから渡した。最後に1コマずつ書き出して音声と重ねる
- **制限**：用意された声は1回に2人まで（3人以上は別々に作ってつなぐ）。自作の声の保存には件数と期間の上限あり。他人（実在の声優・タレント）の声を真似させない。規約は変わるので最新を確認

### 動画B「Claude Code の中で動画を作る（2Dアニメ）」
- 外部の動画生成サービスのクレジットを使わず、Claude Code がコードでアニメを作る（ストーリー動画、ダンス、MV、10分の長尺まで）
- **作れるスタイル**：落書き、クレヨン、折り紙、ワンライン、水彩など。**実写だけはコードでは作れない**（実写が要る部分は外部の動画生成AIを MCP でつないで作っていた）
- **スタイルは2つを組み合わせる**と、ありがちな見た目を避けられる。台本を読ませて「どの段落をどのスタイルで見せるか」をスプレッドシートにしてもらう
- 仕上げの頼み方：音声ファイルを添付し、スタイル表を貼り、「この表のとおりにアニメを作る／音声は添付のまま使い編集しない／テロップの見た目は統一」。冒頭のあとにタイトルと目次を出す。映像が主役の場面ではテロップを出さない
- 1回目で完成ではない。直してほしい所を指示して作り直す。10分の動画でおよそ1時間
- **量産に見えない工夫**：毎回同じスタイル・同じサムネにしない。投稿の頻度も気をつける。長く続けるなら、人が顔を出して視聴者とやりとりするものを大事にする（完璧すぎる映像はやがて飽きられる）

## 2. この環境でできること・できないこと（2026-09-30 確認）

| 項目 | 状態 |
| --- | --- |
| Gemini API（generativelanguage.googleapis.com） | つながる。環境変数 `GEMINI_API_KEY` を登録すれば、声の作成と文字起こし（読み間違いチェック）を自動化できる |
| AI Studio の画面での作業 | 三浦さんがブラウザで行い、書き出した音声ファイルをチャットに渡す方法でもよい |
| Chromium（Playwright） | 使える。HTMLアニメを1コマずつ撮って ffmpeg で MP4 にできる |
| npm（Remotion など） | 入れられる |
| ElevenLabs、Hugging Face（Whisper のモデル） | つながらない（ネットワーク設定で止められている） |
| 実写の動画生成（Kling など） | この環境にはつないでいない。使うなら MCP の接続が必要 |

TTS のモデル名は変わるので、AI Studio の「Get code」に出るモデル名を使う（推測で書かない）。

## 3. 提案用のパターン（三浦さんの商品ごと）

提案するときは3つくらいに絞り、例えで説明してから選んでもらう。

| パターン | 例え | 向いている商品 | 見た目 | 声 |
| --- | --- | --- | --- | --- |
| A. 黒板授業 | 先生が黒板に書きながら話す | Q1講座「独立できない理由」（7回） | ホワイトボード手書き＋インフォグラフィック（数字・グラフが動く） | 1人（落ち着いた先生声） |
| B. ラジオ番組 | 司会とアシスタントのかけ合い | ナーチャリング音声、Q2「毎日5分の音声」 | 波形と大きな一言＋ワンライン画、背景は紺 | 2人（語り手＝三浦役、聞き手＝相づち・短い質問） |
| C. 紙芝居ドキュメンタリー | 紙芝居で実話を聞く | Q3「止まっていた人と動けた人の分かれ道」 | 水彩＋切り絵、人物はシルエット（実名・顔は出さない） | 1〜2人 |
| D. すごろくシミュレーション | ボードゲームで1年を進む | Q4「独立1年目シミュレーション」 | ゲーム盤・コマ・月ごとのイベントカード、お金メーター | 1人＋効果音 |
| E. 現場のチョーク解説 | 作業台の上で図解 | 仕事内容・季節の波・単価の話 | 折り紙風のエアコン分解図＋カレンダーのアニメ | 1人 |
| F. いまのスライド型 | 動く紙芝居 | 急ぎ・量産 | `ai-voice-video/build.py` | 1人 |

組み合わせの候補（2つを混ぜる）：手書き×インフォグラフィック、水彩×切り絵、ワンライン×大きな文字、折り紙×図解、クレヨン×写真風の背景（写真は使えるものだけ）。
同じ講座の中でも、導入・本題・実例・ワークでスタイルを変えてよい（スタイル表で決める）。

## 4. プロンプト集（コピーして使う）

### 4-1. 声選び（三浦さんが AI Studio で行う）
- Generate speech → 設定 → 言語「日本語」、使い道「チューター」などで絞る
- 講座の同じ一文（例「独立できない理由は、お金でも時期でもありませんでした。」）を3つの声で鳴らして比べる
- 決めた声の名前をメモ（語り手・聞き手の2つ）

### 4-2. 読み上げ用の台本（Claude に頼む）
```
Gemini TTS で読み上げる台本を書いてください。目で読む文章ではなく、耳で聞く文章にします。

1. 何をどのくらい：〔講座名・第何回〕を〔1人語り／2人の掛け合い〕で〔◯分〕。元の台本は〔貼る〕
2. 登場人物：語り手＝ありがとうグループの三浦（事実と教えを運ぶ役）。聞き手＝受講生（驚き・相づち・短い質問だけ）
3. 守ること：数字は元の台本のものだけ。実績は約束ではないと添える。人名・他社名・本の名前は出さない。[三浦が記入]の部分は飛ばす
4. 出力の形：1行ずつ「話者｜演技の指示（短い英語）｜セリフ」。同じ話者が続く部分は1行にまとめる（掛け合いは交互に固定のため）。
   地名・人名などの固有名詞はひらがなで書く。読み間違えそうな熟語は言い換える。長い間のタグは使わない
最後に、ぼかした所・使わなかった表現と、その理由を箇条書きで添えてください。
```

### 4-3. スタイル表（Claude に頼む）
```
この台本を段落ごとに分け、どのスタイルの組み合わせで見せるかを表にしてください。
列：番号／台本の段落／スタイル（2つの組み合わせ）／画面に出すもの／テロップ（出す・出さない）／秒数の目安
使える候補：手書きホワイトボード、インフォグラフィック、水彩、切り絵、ワンライン、折り紙、クレヨン、紙芝居、ゲーム盤
ルール：導入のあとにタイトルと目次を出す。映像が主役の場面はテロップを出さない。同じスタイルが3場面以上続かない。色は紺#1F3A5Fとオレンジ#E8833A
```

### 4-4. 映像（Claude Code に頼む）
```
HTMLファイル1つで動く解説アニメを作ってください（1920×1080）。
1. 見た目：〔スタイル表を貼る〕。ロゴは右上。色は紺#1F3A5Fとオレンジ#E8833A
2. 時間：〔どの言葉が何秒に来るかの一覧を貼る〕。言葉が出る瞬間に図や線も動かす
3. 書き出しの仕掛け：window.seek(秒) を呼ぶとその瞬間の絵を描いて止まるようにする（乱数は固定、時間は seek の値だけで決める）
作ったら自分で20か所以上を画像に書き出し、文字のはみ出し・重なり・エラーがないか確かめてから渡してください。
```

### 4-5. 仕上げ（Claude Code）
```
添付の音声を編集せずにそのまま使い、スタイル表のとおりに映像をつけて MP4 にしてください。
テロップの見た目は全編で統一。冒頭のあとにタイトルと目次。映像が主役の場面はテロップなし。
```

### 4-6. 腕試し（動画Bのテスト用）
```
好きな内容を自由に選んで、信じられないほど魅力的な2Dアニメーションを作ってください。
長さは1分、つながりのあるストーリーで、日本語の音声を含めてください。私を驚かせてください。
想像もしなかったような、本当に可能な能力を存分に見せてください。必要な道具は自分で入れて使ってください。
```

## 5. できている道具

- `ai-voice-video/board/`：**黒板授業（パターンA）の仕組み**。二人の掛け合い台本 → 行ごとに声 → 時間の一覧 → HTMLの黒板アニメ（`template.html`、`window.seek(秒)` で止まる）→ Chromium で1コマずつ撮って MP4
  - 台本の形式：`話者 | 演技の指示（英語） | セリフ`、`# scene: 名前` で場面を分ける（例 `ai-voice-video/scripts/Q1第1回_冒頭_掛け合い.txt`）
  - 場面ごとの絵は `board/scenes/講座名.js` に書き、`--scenes` で渡す（`at(場面, 行, 秒)` で「その行が始まって何秒後」、`mid(場面, 行, 割合)` で「その行の途中」に出す）
  - 絵を足したら、各場面の終わりの秒数で `--preview` を出し、文字と線の重なり・黒板からのはみ出しを必ず目で確かめる（1回目はほぼ必ずどこか重なる）
  - 書き出しは30fpsで、1分あたり約2分かかる
  - 確認用の静止画：`python3 board.py 台本 名前 --preview 26,48,87`
  - 声は今は仮（Open JTalk、語り手と聞き手で高さを変えている）。`tts_line()` を Gemini TTS に替える
- `ai-voice-video/Chrome用プロンプト_Gemini声とAPIキー.md`：Chrome の Claude に声選びとAPIキー登録を手伝わせるプロンプト

## 6. 作業の流れ（このリポジトリで）

1. 台本（ドライブ）→ 4-2 で読み上げ用に直す → 三浦さんが確認
2. 音声：Gemini TTS（`GEMINI_API_KEY` があれば自動。なければ三浦さんが AI Studio で作って WAV を渡す）
3. 読み間違いチェック：音声を Gemini で文字起こし → 台本と比べて違う所だけ出す → 固有名詞はひらがな、熟語は言い換え → 読みのメモ（`READING_FIX`）に足す
4. 時間の一覧：1行ずつ音声を作る場合は長さから計算できる。まとめて作った場合は文字起こしの時刻を使う
5. 4-3 のスタイル表 → 4-4 で HTML アニメ → Chromium で1コマずつ撮る → 音声と重ねて MP4
6. 三浦さんが見て直しを指示 → 作り直す

## 7. 注意

- **AI Studio の無料枠に入れた文章と返答は、Google の学習に使われることがあると同意画面にある**（動画Aより）。有料で売る講座の台本は、有料のAPI（規約を確認）で作るか、公開してよい部分だけにする
- 声の権利：実在の人の声を真似させない。用意された声を使う
- 講座の数字は実績・約束として言わない（元の台本の注意書きを残す）
- YouTube に出すもの（ナーチャリング用など）は、スタイルとサムネを毎回変える。三浦さん本人の顔出し・語りかけと組み合わせると長続きしやすい
