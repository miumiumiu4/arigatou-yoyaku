# 読者限定キャンペーン 予約サイト セットアップ手順

例え話でいうと、**GitHub Pages＝看板（お客さんが見るページ）**、**Googleスプレッドシート＝帳簿（予約と紹介料の記録）**、**Apps Script（GAS）＝看板と帳簿をつなぐ受付係**、**PayPal＝集金係** です。
順番は「帳簿 → 受付係 → 集金係 → 看板」の順に作ると、途中で行き来せずに済みます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 読者限定の予約ページ（金額自動計算・紹介コード対応） |
| `recruit-site/` | **業務委託スタッフ募集ページ一式（別リポジトリ `arigatou-recruit` で独立公開する用）**。使い方は `recruit-site/README.md` |
| `Code.gs` | スプレッドシート側の受付プログラム（予約記録・確認メール・PayPal請求書・紹介集計） |

---

## STEP 1：帳簿（Googleスプレッドシート＋GAS）　所要 約15分

1. Googleドライブで **スプレッドシートを新規作成**。名前は「読者限定キャンペーン予約管理」など。
2. メニュー **拡張機能 → Apps Script** を開く。
3. 最初から入っているコードを全部消して、`Code.gs` の中身を貼り付け → 保存。
4. 上の関数選択で **`setup`** を選び **▶ 実行**。初回は「権限の確認」が出るので、自分のGoogleアカウントで許可（「詳細」→「安全ではないページに移動」→ 許可）。
   → シートに「予約」「紹介集計」「面接申込」の3枚が自動で作られます。
5. 左メニュー **プロジェクトの設定（歯車）→ スクリプト プロパティ** に追加：
   - `NOTIFY_EMAIL` ＝ 予約通知を受け取る自分のメールアドレス
   - `PAYPAL_ENV` ＝ `live`（テストするなら `sandbox`）
   - `PAYPAL_CLIENT_ID` ／ `PAYPAL_SECRET` ＝ STEP 2 で取得
6. **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**
   - 説明：任意 ／ 実行ユーザー：**自分** ／ アクセスできるユーザー：**全員**
   - 「デプロイ」→ 表示される **ウェブアプリのURL（…/exec）** をコピー。これが受付係の住所です。
7. 左メニュー **トリガー（時計）→ トリガーを追加**
   - 関数：`checkPayPalPayments` ／ イベントのソース：時間主導型 ／ 1時間おき
   → PayPalで入金があると、予約シートの「支払い状況」が自動で「支払済」になり、紹介集計に反映されます。

> コードを直したあとは、**デプロイ → デプロイを管理 → 編集 → バージョン「新バージョン」→ デプロイ** が必要です（URLは変わりません）。

## STEP 2：集金係（PayPal請求書の自動送信）　所要 約10分

※ ここは公嗣さん自身のPayPalアカウントでの操作になるので、こちらでは代行できません。

1. PayPalの **ビジネスアカウント** でログイン。
2. https://developer.paypal.com/dashboard/ → **Apps & Credentials** → 右上を **Live** に切替 → **Create App**。
3. 作成したアプリの **Client ID** と **Secret** を、STEP 1-5 のスクリプトプロパティに貼る。
4. 動作確認：予約ページから「PayPal請求書」を選んでテスト予約 → 自分のメールに請求書が届けばOK。
   届かない場合は、予約シートの右端「メモ」列にエラー内容が書き込まれます。

自動でやっていること：予約フォーム送信 → 明細付きの請求書をPayPalで作成 → お客様のメールに送信 → 1時間おきに入金チェック → 支払済に更新。

## STEP 3：看板（GitHub Pages）　所要 約10分

### GitHubアカウントの有無を確認する
- https://github.com/login でログインを試す。パスワードリセットで自分のメール（miumiumiu4@gmail.com 等）が見つかればアカウントあり。
- なければ https://github.com/signup で作成（無料）。※アカウント作成は公嗣さんご自身で行ってください。

### リポジトリを作って公開する
1. GitHub右上 **＋ → New repository**
   - Repository name：`arigatou-yoyaku`
   - Public を選択 → **Create repository**
2. 「uploading an existing file」のリンクをクリック → `index.html` `README.md` をドラッグ＆ドロップ → **Commit changes**
   （`Code.gs` はスプレッドシート側にも貼り済みなので、バックアップとして置いておきます）
3. リポジトリの **Settings → Pages**
   - Source：Deploy from a branch ／ Branch：`main` ／ フォルダ：`/ (root)` → Save
4. 1〜2分待つと、`https://（ユーザー名）.github.io/arigatou-yoyaku/` で公開されます。
   - 予約ページ：`.../arigatou-yoyaku/` または `.../arigatou-yoyaku/index.html`
   - 募集ページはこのサイトには含まれません。`recruit-site/` の中身を別リポジトリ `arigatou-recruit` に置いて `https://miumiumiu4.github.io/arigatou-recruit/` で公開します（手順は `recruit-site/README.md`）

### 貼り替える箇所（必須）
- `index.html` の `CONFIG.GAS_URL` に STEP 1-6 のURLを貼る
- `index.html` の `CONFIG.PRICE_SET3`（3点セットの1台あたり料金）をHPの正規料金に合わせる
- GitHub上で編集する場合：ファイルを開く → 鉛筆アイコン → 修正 → Commit changes（数十秒で反映）

### Claude Codeと連携して今後の修正を任せる場合
Claude Codeの「リポジトリを選択」で `arigatou-yoyaku` を選べるようにするには、GitHubアプリの連携時にこのリポジトリへのアクセスを許可してください。連携後は「予約ページの文言を変えて」のような依頼で直接編集・公開できます。

## 運用のしかた

### 予約が入ったら
- `NOTIFY_EMAIL` に通知メールが届く → 「予約」シートを確認 → お客様に作業日を連絡 → 「作業確定日」列に入力
- 当日払いの方は、作業後に「支払い状況」を **支払済** に変更（プルダウン）

### 紹介料の管理
- 紹介者には、予約ページURLの末尾に `?ref=紹介者コード` を付けたリンクを渡す
  例：`https://xxx.github.io/arigatou-yoyaku/?ref=tanaka`
- 「紹介集計」シートのA列に紹介者コードを追加すると、予約件数・支払済件数・支払うべき紹介料（通常価格の20%、駐車場代除く）が自動集計されます
- 紹介料は「支払済」の予約だけが対象（未払い・キャンセルは含まれません）

### 面接申込が入ったら（募集ページ `arigatou-recruit` から）
- 募集ページの申込も、同じ受付係を通じてこのスプレッドシートの「面接申込」シートに入ります。候補日3つから日程を決めて「面接日確定」列に記入 → 応募者へ連絡

### 締切
- `index.html` の `CONFIG.DEADLINE`（2026-09-30 23:59）を過ぎると、フォームが自動で「終了」表示になります
