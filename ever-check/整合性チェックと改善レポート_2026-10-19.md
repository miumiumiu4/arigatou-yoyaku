| 20本以上 | 60万円〜 | 約65% | 開封25%・第1回視聴40%・予告メールのクリック5%程度 |
| **35本以上（中央）** | **104万円〜** | **約45%** | 開封30%・電話フォーム90件・3回払いが使われる |
| 50本以上 | 149万円〜 | 約25% | LINEからの新規登録が200人を超え、11/18夜までに15本 |
| 75本以上 | 224万円〜 | 約10% | 強い側（購入率3%）。会議の枠54では足りず11/23に追加 |

期待値（確率で重みづけした平均）＝**約35本・約100万円**。「売れる確率」を1人あたりで言うと、名簿の**約65人に1人（1.5%）**が買う計算。

> 例え：1,870人が通る商店街に自動販売機を1週間だけ置く。1.5%は「100人通って1〜2人が買う」。3回払いは「千円札しか持っていない人にも買えるようにした」効果で、通る人は増えないが、買う人が1〜2割増える。

### 3-2. 確率を動かすもの（大きい順）

| 要因 | 動く幅（中央35本に対して） | 今の状態 | 手 |
|---|---|---|---|
| 0日目メールの到達と開封（古い名簿・DKIM） | 開封20%未満なら −30%（約25本）／30%以上なら +20%（約42本） | 10/19の1回目で分かる | 10/20に開封率を見て、件名・差出人名・送る時間を10/27までに直す（B組に反映） |
| 28・32日目メールの「一括のみ」表記（1-1） | 直さないと −5〜10% | 未反映 | 1-1の一言で直す |
| 「本番は第4回から」（B-1）＋25〜45分 | 反映済み（中央に織り込み） | ✓ | — |
| LINEからの新規登録数 | 100人→+1本／300人→+9本 | 10/19 20:00配信 | 10/20朝に登録数を見る。少なければ10/22に2通目（第2・3回の案内）を検討 |
| 11/18夜までの3日間の本数 | 3日間で全体の約4割が決まる | — | 11/18に「3日目までの本数×2.5」で最終を読み、弱ければ20〜21日目に事例メールを1通足す |
| 買った人がログインできない（1-2） | 本数は変わらないが、会議の予約率と評判に −（苦情・返金要求） | 未反映 | 1-2の直し |

### 3-3. その先（加盟）

購入者の3〜5割が集客戦略会議を予約し、会議の1〜2割が加盟に進む仮定なら、11月販売からの加盟は**12月〜1月に0〜3件**（中央1件）。1000万円/月はプロジェクト全体（講座＋加盟＋55万円講座＋海外版）で数える決定なので、11月のエバーは「講座約100万円＋加盟の種1件」が現実的な目標。

## 4. 広告での販売予測（ファネルA 資料請求型・B 60分動画型）

前提：計画書（ever-ads/00_計画書）の目安と、阿部さんファネルの実測（登録1件 約10,630円・LP登録率4.2%）、旧FCファネルの実績（加盟1件あたり広告費 約30〜70万円）。

### 4-1. 11/9〜15 コンセプトテスト（約9万円）

- 登録1件 8,000〜12,000円なら **8〜11人**の登録。講座の購入は出ない（Aは5週間後、Bは少なすぎる）。
- 分かるのは「10案のうちどの切り口がクリックされ、登録されるか」だけ。**売上の予測材料ではなく、11/24以降の広告文を決めるテスト**。
- 登録者は11/16〜22の一斉案内から自動で外れ、12月に自分の28日目の案内を受ける（決定どおり）。

### 4-2. 11/24〜 A/B本番テスト（各20万円・約2か月）

| | A 資料請求型 | B 60分動画型 |
|---|---|---|
| 登録単価（目安／弱い） | 8,000円以下／15,000円超 | 15,000円以下／25,000円超 |
| 20万円での登録数 | 約13〜25人 | 約8〜13人 |
| 第1回視聴／動画を50分まで見た率 | 50%以上 | 30%以上 |
| 購入率（目安） | 3%（5週間後） | 3%（7日以内） |
| **20万円での講座本数** | **0.4〜0.75本** | **0.25〜0.4本** |
| 加盟 | ほぼ0（確率の話） | ほぼ0 |

つまり**40万円のテストで売れる講座は0〜2本**。このテストの目的は「登録単価・視聴率・購入率・面談予約率」を測ること。売上で判定しない（計画書どおり）。

### 4-3. 本格運用の見込み（2027年1月以降、各ファネル月60万円＝計120万円/月の場合）

| | 弱い | 中 | 強い |
|---|---|---|---|
| A 登録単価／登録数 | 15,000円／40人 | 10,000円／60人 | 8,000円／75人 |
| B 登録単価／登録数 | 25,000円／24人 | 15,000円／40人 | 12,000円／50人 |
| 購入率 A／B | 1%／1% | 3%／3% | 5%／5% |
| **講座 本/月** | **0.6本** | **3本** | **6本** |
| 会議予約率→加盟率 | 30%→10% | 40%→20% | 50%→25% |
| **加盟 件/月** | **0.02件（ほぼ0）** | **0.24件（4か月に1件）** | **0.8件（5週間に1件）** |
| 月あたり売上（講座＋加盟を月平均） | 約2万円 | 約9万円＋約80万円＝**約90万円** | 約18万円＋約260万円＝**約280万円** |
| 広告費120万円に対して | 大赤字→止める | 少し赤字→加盟率を上げるか単価を下げる | 黒字→予算を増やす |
| 加盟1件あたり広告費 | — | 約500万円 | 約150万円 |

読み方：
- 講座（29,800円）は広告費を回収しない。**採算は「加盟1件あたり広告費」で決まる**。旧FCファネルの実績30〜70万円に対し、新ファネルは「中」でも約500万円と遠い。これは「購入者だけが面談に来る」設計の代償（旧ファネルは動画を見た人が直接、無料セッションに来た）。
- だから1月の判定は「講座1本あたり広告費50万円以下」（計画書）に加えて、**「会議の予約率40%以上・会議→加盟20%以上」が出るか**で決める。出なければ、面談の入口（購入前に会議に来られる道）を再検討する材料になる。
- 月1000万円に対しては、広告ファネル単体では「強い」でも約280万円。残りは旧FCファネルの入口（止めない決定はしていないが、戻さないと決めた）か、別の入口（YouTube・LINE・紹介）で加盟を月2件にする必要がある。

## 5. 稼働後に解析を繰り返して、数字を上げる仕組み

> 例え：自動販売機に「売上カウンター」を付けて、毎週月曜に数字を読み、ボタンの位置を1つだけ動かす。1週間で1か所だけ変えるのがコツ。2か所同時に変えると、どちらが効いたか分からなくなる。

### 5-1. 数字の置き場（すでにあるもの）

| 数字 | どこにあるか | 誰が書くか |
|---|---|---|
| 配信・開封・クリック | UTAGE mail_stats（シナリオ fGqog… と一斉配信） | UTAGE自動 |
| 第1回を開いた・無料公開の登録・購入・予約 | 分析シート「顧客ログ」events（受け口GAS） | 自動 |
| 電話フォームの登録 | 電話リスト（顧客ログ） | 自動 |
| 会議アンケート | 分析シート「会議アンケート_要約（匿名）」 | 自動 |
| 広告費・登録・単価 | 阿部さんの「資料請求の自動記録」シート「エバー広告_月次ビュー」 | Meta→手入力（週1） |
| 加盟の結果 | 「加盟アンケート」タブ＋手入力（会議参加・加盟） | 三浦さん・クローザー |
| 週次の数字 | **新規：分析シートに「エバー_週次KPI」タブ**（列は ever-check/週次KPI_テンプレ.csv） | 週次レポートが追記 |

### 5-2. 毎週の型（月曜の朝）

1. 先週の数字を「エバー_週次KPI」に1行足す（テンプレの列）。
2. 判定表（5-3）で「良い／ふつう／弱い」を付ける。
3. 弱いものが1つあれば、手の一覧（5-4）から**1つだけ**選んで、その週に変える。
4. 週報を ever-ads/週報/ に置く（書き方は ever-check/週報テンプレ.md）。三浦さんに決めてもらうことは選択肢カードで。
5. 変えたことは「いつ・何を・前後の数字」を週報に残す（次の週にその効果を見る）。

やり方の候補：A 毎週月曜7:00にクラウドの定期タスクが週報スレッドを作る／B 三浦さんが「週報」と書いたときだけ／C MacのLaunchAgentでシートに数字を集め、週報はスレッドが書く。おすすめはA（忘れない）。定期タスクは三浦さんのOK後に作る。

### 5-3. 判定表（段階ごと）

| 段階 | 数字 | 良い | 弱い | 最低サンプル |
|---|---|---|---|---|
| 入口 | 0日目の開封率 | 30%以上 | 20%未満 | 200通 |
| 入口 | LINE・YouTube・広告からの登録数/週 | 50人以上 | 10人未満 | — |
| 入口 | 広告の登録単価 A／B | 8,000／15,000円以下 | 15,000／25,000円超 | 広告費5万円 |

| 教育 | 電話フォーム登録率（名簿に対して） | 5%以上 | 2%未満 | 500人 |

| 販売 | 3回払いの割合 | 2〜4割 | 0（表示されていない） | 購入10本 |
| 出口 | 購入→会議予約率 | 40%以上 | 20%未満 | 購入10本 |

| 出口 | 加盟1件あたり広告費 | 70万円以下 | 200万円超 | 加盟2件 |

「最低サンプル」に届くまでは判定しない（1〜2日の数字で変えない）。

### 5-4. 弱いときの手（1週間に1つ）

| 弱い数字 | 手（上から順に試す） |
|---|---|
| 開封率 | ①件名を「質問形」に（例：「あのとき止まった理由は、何でしたか？」は残す）②送る時間を7:00→20:00 ③差出人名の表記 ④DKIM/迷惑メール報告の確認（Gmail Postmaster） |

| 電話フォーム率 | ①「お電話することがあります」の一文を入れたうえで、第2回の見どころを1行 ②番号欄を任意にしてメール認証にする（三浦さん判断） |
| 予告クリック率 | ①26日目に「第4回の最初の5分」を無料で見せる ②特典5つを箇条書きで先に出す |
| 購入率 | ①28日目に3回払いを明記（1-1）②32日目Q&Aに「第1〜3回はもう見ました」の答え ③20〜21日目に事例メールを1通足す ④締切前日に「迷っている人へ」の短い動画 |
| 3回払いの割合0 | 価格の「表示する」が入っているか確認（テスト購入のあと） |
| 会議予約率 | ①購入者0日目にログイン情報と予約ボタンを同じメールに ②3日目メールに「先に日程だけ押さえてOK」③枠が10日先までしか見えない設定を14日先に |
| 会議→加盟率 | ①台本の「加盟金330万円を最初に」のあとに「分割・融資の道」を必ず ②3日間準備動画の宿題を会議の最初に読む ③会議アンケート要約で「すでに現場に出ている人」の割合を見て台本を分ける |
| 広告の登録単価 | ①コンセプトテストで上位2案に絞る ②LPの最初の画面を広告文と同じ言葉に ③年齢・地域を絞る |
| Bの視聴率 | ①リマインドにLINEを足す ②「今すぐ見られる回」を上に ③20時だけにして集中させる |

### 5-5. やらないこと（決まり）

- 2つ以上を同じ週に変えない。
- 「今だけ・閉じたら見られない」は仕組みで本当にそうなる場合だけ書く。
- 数字は公式シートの「確定」だけを使う。名前・メールの入ったタブは解析スレッドでは読まない（要約タブだけ）。
- 外に出る変更（UTAGE保存・配信・公開）は三浦さんのOK後。Macの本人確認が要る操作は、1行の文面で頼む。
